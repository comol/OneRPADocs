# СППР

Сервер ищет по конфигурации **1С:Система проектирования прикладных решений** 2.0.11.11:
метаданные, модули, формы и встроенная справка самой СППР. Отдельный снимок двух
справочников позволяет получить проект и карточки его технических проектов с их статусами.
Сервер читает оба снимка с диска.

С 05.11.2026 СППР входит в основной состав MCP. Образ на Docker Hub не опубликован,
лицензионного ключа нет, порта нет. Установщик Docker-поставки контейнер не запускает
и в `mcp.json` запись не добавляет. Инструкция дистрибутива — `servers/10_SPPR.md`.

## Как запущен

Процесс со транспортом stdio. Его поднимает MCP-клиент на машине, где развёрнут
каталог исходников `pre-alpha/MCP_SPPR`. Отдельного URL `/mcp` нет.

Индекс — SQLite FTS5, файл `data/sppr.sqlite3` в каталоге проекта. Путь можно
задать переменной `SPPR_INDEX_DB`.

Карточки берутся из `data/projects.json`. Для обновления запустите из каталога
сервера `scripts\export_projects.ps1 -Base <каталог файловой базы>` в Windows PowerShell
той же разрядности, что и зарегистрированный COM-коннектор 1С (`V83.COMConnector`).
Пользователь базы задаётся параметром `-User`, по умолчанию «Администратор».
Скрипт читает справочники «Проекты» и «Технические проекты» через COM и заменяет файл
после успешной выгрузки. Сервер перечитывает снимок при каждом запросе.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `sppr_index_status` | Готовность индекса, число документов и фрагментов |
| `sppr_search` | Полнотекстовый поиск. Параметры: `query`, `limit`, `source_prefix` |
| `sppr_explain` | Фрагменты для объяснения темы |
| `sppr_traceability` | Фрагменты по названию требования, функции, сценария или объекта метаданных |
| `sppr_projects` | Записи справочника «Проекты» с кодом, наименованием и UUID |
| `sppr_technical_projects` | Технические проекты. Фильтры `project_uuid` и `status` (полное русское название) |
| `sppr_object` | Карточка по `uuid`. Для технического проекта доступны также статус, раздел, целевая задача, версия и простое текстовое поле целей |

Оба списка принимают `offset` и `limit` (по умолчанию 200, максимум 500).
Ответ содержит `total`, `truncated`, дату выгрузки и имя базы. В `sppr_index_status`
поле `ready` относится к индексу конфигурации, `project_snapshot.ready` — к карточкам.

Каждый фрагмент содержит источник, заголовок, раздел, текст и SHA-256.
`sppr_traceability` возвращает кандидатов из текста конфигурации, а не связи записей базы.

Ресурсы MCP: `sppr://about` — краткое описание сервера, `sppr://threat-model` — модель угроз.
