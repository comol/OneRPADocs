# СППР

Сервер ищет по конфигурации **1С:Система проектирования прикладных решений** 2.0.11.11:
метаданные, модули, формы и встроенная справка самой СППР. Записи проектов в базе
(технические проекты, функции, подсистемы прикладного решения) в индекс не входят.
Сервер базу не изменяет.

С 05.11.2026 СППР входит в основной состав MCP. Образ на Docker Hub не опубликован,
лицензионного ключа нет, порта нет. Установщик Docker-поставки контейнер не запускает
и в `mcp.json` запись не добавляет. Инструкция дистрибутива — `servers/10_SPPR.md`.

## Как запущен

Процесс со транспортом stdio. Его поднимает MCP-клиент на машине, где развёрнут
каталог исходников `pre-alpha/MCP_SPPR`. Отдельного URL `/mcp` нет.

Индекс — SQLite FTS5, файл `data/sppr.sqlite3` в каталоге проекта. Путь можно
задать переменной `SPPR_INDEX_DB`.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `sppr_index_status` | Готовность индекса, число документов и фрагментов |
| `sppr_search` | Полнотекстовый поиск. Параметры: `query`, `limit`, `source_prefix` |
| `sppr_explain` | Фрагменты для объяснения темы |
| `sppr_traceability` | Фрагменты по названию требования, функции, сценария или объекта метаданных |

Каждый фрагмент содержит источник, заголовок, раздел, текст и SHA-256.
`sppr_traceability` возвращает кандидатов из текста конфигурации, а не связи записей базы.
