# CodeMetadataSearchServer

Поиск по метаданным, справке конфигурации и паттернам кода.

## Назначение

CodeMetadataSearchServer индексирует метаданные вашей конфигурации 1С и код модулей. ИИ получает возможность:

- Искать объекты конфигурации по названию и назначению
- Находить реквизиты и формы
- Анализировать код модулей
- Понимать структуру вашей конфигурации

## Доступные инструменты MCP

ИИ получает следующие инструменты:

| Инструмент | Описание |
|------------|----------|
| `metadatasearch` | Поиск объектов конфигурации по имени или описанию |
| `codesearch` | Поиск по тексту кода модулей |
| `helpsearch` | Поиск по HTML-справке конфигурации |

{% hint style="info" %}
Каждый инструмент можно отключить через переменные `INDEX_METADATA`, `INDEX_CODE`, `INDEX_HELP`. При отключении индексации соответствующий инструмент убирается из MCP.
{% endhint %}

## Возможности

ИИ получает инструменты для:

- Поиска объектов конфигурации
- Поиска реквизитов
- Поиска по коду
- Поиска по справке конфигурации

## Примеры использования

- "Какие реквизиты есть у документа РеализацияТоваров?"
- "Найди все обработки, связанные с печатью"
- "Где в конфигурации используется регистр ОстаткиТоваров?"
- "Покажи структуру справочника Номенклатура"

## Требования

- Docker Desktop с WSL2
- Лицензионный ключ
- Embedding модель (LM Studio или CPU)
- **Выгрузка конфигурации** из Конфигуратора

## Порт

**8000**

## Образ Docker

```
comol/1c_code_metadata_mcp:latest
```

## Подготовка данных

Требуется выгрузить из Конфигуратора:

1. **Отчет из конфигурации** (текстовый отчет по метаданным)
2. **Выгрузка в файлы** (файлы модулей)

Подробнее: [Подготовка данных](podgotovka-dannyh.md)

## Быстрый старт

```powershell
docker run -d -p 8000:8000 `
  --name 1c_code_metadata_mcp `
  -e LICENSE_KEY=YOUR_LICENSE_KEY `
  -e METADATA_PATH="/app/metadata" `
  -e CODE_PATH="/app/code" `
  -v "E:/1C_Export/Report:/app/metadata" `
  -v "E:/1C_Export/Files:/app/code" `
  -v "E:/bases/mcp_codemetadata:/app/chroma_db" `
  comol/1c_code_metadata_mcp:latest
```
