# FormsServer

Контекст для генерации форм 1С — предоставляет ИИ схемы форм.

## Назначение

FormsServer даёт ИИ доступ к XSD и JSON схемам форм 1С. Это позволяет ИИ генерировать корректный XML-код форм, понимая структуру элементов и их атрибуты.

## Возможности

ИИ получает инструменты для:

- Получения XSD схемы форм 1С
- Получения JSON схемы форм 1С
- Понимания структуры элементов формы

## Примеры использования

- "Создай форму списка для справочника Номенклатура"
- "Добавь на форму таблицу с колонками..."
- "Сгенерируй XML формы документа"

## Требования

- Docker Desktop с WSL2
- Лицензионный ключ

{% hint style="success" %}
Этот сервер можно запустить сразу — он содержит встроенные схемы форм.
{% endhint %}

## Порт

**8011**

## Образ Docker

```
comol/1c_forms:latest
```

## Инструменты MCP

| Инструмент | Описание |
|------------|----------|
| `get_xsd_schema()` | Возвращает XSD схему форм 1С |
| `get_json_schema()` | Возвращает JSON схему форм 1С |

## Быстрый старт

```powershell
docker run -d -p 8011:8011 `
  --name 1c_forms_mcp `
  -e LICENSE_KEY=YOUR_LICENSE_KEY `
  comol/1c_forms:latest
```
