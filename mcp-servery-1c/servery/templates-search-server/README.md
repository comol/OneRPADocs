# TemplatesSearchServer

Поиск по шаблонам кода 1С.

## Назначение

TemplatesSearchServer предоставляет ИИ библиотеку готовых шаблонов и паттернов кода 1С. Сервер содержит публичные шаблоны и позволяет добавлять собственные.

## Возможности

ИИ получает инструменты для:

- Поиска типовых шаблонов кода
- Использования готовых решений
- Соблюдения стандартов кодирования

## Примеры использования

- "Как обойти результат запроса?"
- "Покажи шаблон обработки проведения документа"
- "Как правильно работать с транзакциями?"
- "Шаблон формы с динамическим списком"

## Особенности

- Содержит публичные шаблоны с [fastcode.im](https://fastcode.im/Templates)
- Веб-интерфейс для редактирования шаблонов
- Возможность добавления собственных шаблонов

## Требования

- Docker Desktop с WSL2
- Лицензионный ключ
- Embedding модель (LM Studio или CPU)

## Порт

**8004**

## Образ Docker

```
comol/template-search-mcp:latest
```

## Быстрый старт

```powershell
docker run -d -p 8004:8004 `
  --name template_search_mcp `
  -e LICENSE_KEY=YOUR_LICENSE_KEY `
  -v "E:/bases/mcp_templates:/app/data" `
  comol/template-search-mcp:latest
```

## Веб-интерфейс

После запуска доступен интерфейс редактирования шаблонов:

```
http://localhost:8004/extend/
```

## Конфигурация Cursor

```json
{
  "mcpServers": {
    "1c-templates-mcp": {
      "url": "http://localhost:8004/mcp",
      "connection_id": "1c_templates_service_001"
    }
  }
}
```
