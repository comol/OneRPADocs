# TemplatesSearchServer

Поиск по шаблонам кода 1С.

## Назначение

TemplatesSearchServer предоставляет ИИ библиотеку готовых шаблонов и паттернов кода 1С. Сервер содержит публичные шаблоны и позволяет добавлять собственные.

## Возможности

ИИ получает инструменты для:

- Поиска типовых шаблонов кода
- Использования готовых решений
- Соблюдения стандартов кодирования

## Примеры использования

- "Как обойти результат запроса?"
- "Покажи шаблон обработки проведения документа"
- "Как правильно работать с транзакциями?"
- "Шаблон формы с динамическим списком"

## Особенности

- Содержит публичные шаблоны с [fastcode.im](https://fastcode.im/Templates)
- **Веб-интерфейс** для просмотра и редактирования шаблонов: `http://localhost:8004/extend/`
- Возможность добавления собственных шаблонов

## Доступные инструменты MCP

ИИ получает следующие инструменты:

| Инструмент | Описание |
|------------|----------|
| `templatesearch` | Поиск шаблонов кода по описанию или ключевым словам |

### templatesearch

Выполняет гибридный поиск по библиотеке шаблонов кода 1С: комбинирует векторный (семантический) и полнотекстовый поиск. Запросы принимаются на русском языке.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `query` | string | Поисковый запрос — описание нужной функциональности или ключевые слова |

**Возврат**: Отформатированная строка с найденными шаблонами (название, описание, код).

**Логика поиска** зависит от длины запроса:
- 1 слово — сначала полнотекстовый, затем векторный поиск
- 2–3 слова — сначала векторный, затем полнотекстовый поиск
- 4+ слов — только векторный поиск

## Веб-интерфейс

После запуска сервера доступен веб-интерфейс для работы с шаблонами:

```
http://localhost:8004/extend/
```

В веб-интерфейсе можно:
- Просматривать все доступные шаблоны
- Добавлять собственные шаблоны
- Редактировать существующие шаблоны
- Удалять шаблоны

## Требования

- Docker Desktop с WSL2
- Лицензионный ключ
- Embedding модель (LM Studio или CPU)

## Порт

**8004**

## Образ Docker

```
comol/template-search-mcp:latest
```

## Быстрый старт

```powershell
docker run -d -p 8004:8004 `
  --name template_search_mcp `
  -e LICENSE_KEY=YOUR_LICENSE_KEY `
  -v "E:/bases/mcp_templates:/app/data" `
  comol/template-search-mcp:latest
```

## Веб-интерфейс

После запуска доступен интерфейс редактирования шаблонов:

```
http://localhost:8004/extend/
```
