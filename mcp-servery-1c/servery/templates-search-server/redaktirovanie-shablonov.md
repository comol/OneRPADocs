# Редактирование шаблонов

TemplatesSearchServer предоставляет веб-интерфейс для редактирования шаблонов.

## Доступ к интерфейсу

После запуска контейнера откройте в браузере:

```
http://localhost:8004/extend/
```

## Возможности интерфейса

### Просмотр шаблонов

- Список всех доступных шаблонов
- Поиск по названию и содержимому
- Фильтрация по категориям

### Редактирование

- Изменение кода шаблона
- Редактирование описания
- Добавление тегов

### Создание новых

- Добавление собственных шаблонов
- Категоризация
- Примеры использования

## Структура шаблона

Каждый шаблон содержит:

| Поле | Описание |
|------|----------|
| Название | Краткое название шаблона |
| Описание | Для чего используется |
| Код | Код на языке 1С |
| Категория | Тип шаблона |
| Теги | Ключевые слова для поиска |

## Категории шаблонов

- **Запросы** — типовые конструкции языка запросов
- **Формы** — работа с управляемыми формами
- **Модули** — структура модулей
- **Транзакции** — работа с транзакциями
- **Файлы** — работа с файловой системой
- **HTTP** — HTTP-запросы
- **Отладка** — отладочный код

## Примеры шаблонов

### Обход результата запроса

```bsl
Выборка = Запрос.Выполнить().Выбрать();
Пока Выборка.Следующий() Цикл
    // Обработка строки
КонецЦикла;
```

### Транзакция с обработкой ошибок

```bsl
НачатьТранзакцию();
Попытка
    // Действия в транзакции
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;
```

## Синхронизация

После изменения шаблонов в веб-интерфейсе:

1. Изменения сохраняются в `/app/data`
2. При монтировании тома сохраняются на хосте
3. При перезапуске контейнера шаблоны доступны

## Резервное копирование

```powershell
# Копирование данных шаблонов
Copy-Item -Recurse "E:\bases\mcp_templates" "E:\backup\mcp_templates_$(Get-Date -Format 'yyyyMMdd')"
```
