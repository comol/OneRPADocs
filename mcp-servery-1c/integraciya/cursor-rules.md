# Cursor Rules для 1С

Правила Cursor (Cursor Rules) помогают ИИ эффективнее использовать MCP-серверы.

## Зачем нужны правила

- ИИ знает о доступных MCP-инструментах
- Автоматически использует серверы при запросах о 1С
- Соблюдает стандарты кодирования 1С
- Понимает специфику языка и платформы

## Готовые правила для 1С

### Репозиторий

[github.com/comol/cursor_rules_1c](https://github.com/comol/cursor_rules_1c)

### Установка

```powershell
# Клонирование репозитория
git clone https://github.com/comol/cursor_rules_1c.git

# Или скачайте архив с GitHub
```

### Использование

1. Скопируйте файлы правил в ваш проект
2. Или добавьте в глобальные правила Cursor

## Содержимое правил

Правила включают:

### Информация о MCP-серверах

```
## Доступные MCP-серверы:
- 1c-docs-mcp: справка платформы
- 1c-ssl-mcp: справка БСП
- 1c-syntax-checker-mcp: проверка синтаксиса
- 1c-templates-mcp: шаблоны кода
```

### Стандарты кодирования

```
## Стандарты кода 1С:
- Имена переменных на русском языке
- CamelCase для процедур и функций
- Комментарии для экспортных процедур
```

### Инструкции по использованию

```
## Правила работы:
- Всегда проверяй синтаксис через MCP
- Используй шаблоны для типовых конструкций
- Уточняй методы через справку
```

## Пример файла правил

```markdown
# Правила для разработки на 1С

## Язык
- Код на языке 1С (BSL)
- Комментарии на русском языке
- Следуй стандартам 1С

## MCP-серверы
При работе с кодом 1С используй доступные MCP-серверы:

1. **Проверка синтаксиса**: используй 1c-syntax-checker-mcp
2. **Справка по методам**: используй 1c-docs-mcp
3. **Справка по БСП**: используй 1c-ssl-mcp для функций БСП
4. **Шаблоны кода**: используй 1c-templates-mcp

## Стиль кода
- Процедуры и функции: ПолучитьОстаткиТоваров()
- Переменные: ТекущийДокумент, СписокТоваров
- Параметры: пДокумент, пСписок

## Работа с запросами
- Используй параметры вместо конкатенации строк
- Добавляй РАЗРЕШЕННЫЕ если нужно
- Комментируй сложные запросы

## Транзакции
- Всегда оборачивай в Попытка-Исключение
- Используй шаблон из templates-mcp
```

```

```

## Создание своих правил

### Структура файла

```markdown
# Название правила

## Описание
Когда применять это правило

## Инструкции
1. Конкретные указания
2. Примеры использования

## Исключения
Когда правило не применяется
```

### Пример: правило для модуля формы

```markdown
# Правила для модулей форм

## Применение
При работе с кодом модуля управляемой формы

## Инструкции
1. Используй 1c-forms-mcp для понимания структуры
2. Серверные процедуры помечай &НаСервере
3. Клиентские процедуры помечай &НаКлиенте

## Структура модуля
1. Переменные модуля
2. Обработчики событий формы
3. Обработчики команд
4. Служебные процедуры
```
