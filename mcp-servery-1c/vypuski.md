# Выпуски beta-образов

Что вошло в beta-сборки CodeMetadataSearchServer и Graph Metadata Search, опубликованные с 9 сентября 2026 года (сборки перечислены по дате публикации; между ними теги не двигались). Теги `latest-beta`, `light-beta` и `arm64-beta` одного выпуска собираются из одного и того же кода; отличаются они только составом зависимостей (см. [Каналы образов](kanaly-obrazov.md)). Сборка опознаётся по digest образа: первые 12 символов `sha256` показывает `docker images --digests`, а полный digest — `docker image inspect <образ> --format '{{index .RepoDigests 0}}'`.

Правила, общие для всех выпусков ниже:

* **Индексы и графы открываются как есть.** Ни один сентябрьский выпуск не меняет формат хранилища zvec, отпечаток индекса или схему графа так, чтобы потребовалась полная переиндексация. Если сборка перечитывает что-то один раз (например, формы графа), это сказано в её строке.
* **Порядок обновления серверов не важен.** Code и Graph не зависят друг от друга: у каждого свои данные и свой лицензионный ключ; обновляйте их по одному в любом порядке.
* **Переменные окружения только добавляются.** Ни одна переменная не переименована и не удалена; новые перечислены в строке выпуска и на странице конфигурации сервера.
