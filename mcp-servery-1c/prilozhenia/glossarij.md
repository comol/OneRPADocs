# Глоссарий

Термины, используемые в документации MCP-серверов.

## Основные термины

### MCP (Model Context Protocol)

Протокол для расширения возможностей LLM через внешние инструменты. Позволяет ИИ получать данные из специализированных серверов.

### RAG (Retrieval-Augmented Generation)

Технология, при которой ИИ сначала ищет релевантную информацию в базе данных, а затем использует её для генерации ответа. Повышает точность и актуальность ответов.

### Embedding

Векторное представление текста. Текст преобразуется в массив чисел, что позволяет измерять "похожесть" текстов по расстоянию между векторами.

### Embedding модель

Нейронная сеть, которая преобразует текст в embedding. Качество модели влияет на качество поиска.

Примеры:
- `Qwen3-Embedding-4B` — высокое качество, GPU
- `multilingual-e5-small` — быстрая, CPU

### ChromaDB

Векторная база данных. Хранит embeddings и позволяет быстро искать похожие по смыслу документы.

### Neo4j

Графовая база данных. Хранит данные в виде узлов и связей. Используется в Graph Metadata Search.

## Термины 1С

### БСП (Библиотека стандартных подсистем)

Набор готовых подсистем для конфигураций 1С: пользователи, отчёты, печать и т.д.

### BSL (Built-in Scripting Language)

Встроенный язык программирования платформы 1С.

### Конфигурация

Прикладное решение на платформе 1С:Предприятие.

### Метаданные

Описание структуры конфигурации: справочники, документы, регистры, реквизиты и т.д.

### Конфигуратор

Среда разработки 1С для создания и редактирования конфигураций.

### EDT (Enterprise Development Tools)

Современная IDE для разработки на 1С на базе Eclipse.

## Термины Docker

### Контейнер

Изолированное окружение для запуска приложения. Содержит код, библиотеки и настройки.

### Образ (Image)

Шаблон для создания контейнера. Хранится в Docker Hub или локально.

### Docker Hub

Публичный репозиторий Docker-образов. MCP-серверы доступны как `comol/*`.

### Том (Volume)

Механизм хранения данных контейнера на хосте. Данные сохраняются при перезапуске контейнера.

### WSL2 (Windows Subsystem for Linux 2)

Подсистема Windows для запуска Linux. Требуется для Docker Desktop на Windows.

### docker-compose

Инструмент для запуска нескольких контейнеров как единого приложения.

## Термины Cursor

### Cursor

IDE на базе VS Code с встроенной поддержкой ИИ и протокола MCP.

### mcp.json

Файл конфигурации MCP-серверов для Cursor.

### Cursor Rules

Правила, определяющие поведение ИИ в Cursor для конкретного проекта.

## Термины сети

### Порт

Номер для идентификации приложения в сети. MCP-серверы используют порты 8000-8011.

### localhost

Адрес локального компьютера (127.0.0.1).

### host.docker.internal

Специальный адрес для доступа из контейнера Docker к хост-машине в Windows/Mac.

### SSE (Server-Sent Events)

Технология для отправки данных от сервера к клиенту. Используется некоторыми MCP-клиентами.

## Термины LM Studio

### LM Studio

Приложение для локального запуска LLM и embedding моделей.

### GGUF

Формат файлов моделей, оптимизированный для локального запуска.

### Квантизация

Уменьшение точности весов модели для снижения требований к памяти. Q8 > Q6 > Q4 по качеству.

### VRAM

Видеопамять GPU. Требуется для запуска моделей на видеокарте.

## Термины Ollama

### Ollama

Инструмент для локального запуска LLM через командную строку.

### Ollama API

OpenAI-совместимый API на порту 11434.
