# Глоссарий

Термины и определения, используемые в документации OneAPA.

## A

**Agent (Агент)**
Автономная программная сущность, способная анализировать запросы, использовать инструменты и формировать ответы с помощью LLM.

**API (Application Programming Interface)**
Интерфейс программирования приложений — набор методов для взаимодействия между программами.

## C

**Chainlit**
Фреймворк для создания веб-интерфейсов чата, используемый в OneAPA для Web UI.

## F

**FastAPI**
Python веб-фреймворк, используемый для REST API Proxy-сервера.

## L

**LangGraph**
Библиотека для создания workflow на основе графов, используемая для оркестрации агентов.

**LLM (Large Language Model)**
Большая языковая модель — нейронная сеть для обработки и генерации текста (GPT-4, Claude, Llama).

## M

**MCP (Model Context Protocol)**
Открытый протокол для взаимодействия LLM с внешними инструментами и данными.

## O

**Ollama**
Инструмент для локального запуска LLM моделей.

**On-Premise**
Развёртывание системы в инфраструктуре заказчика (не в облаке).

## P

**Prompt (Промпт)**
Текстовая инструкция для языковой модели, определяющая её поведение.

**Proxy-сервер**
Компонент OneAPA, обеспечивающий взаимодействие с LLM провайдерами.

## R

**RAG (Retrieval-Augmented Generation)**
Технология обогащения ответов LLM данными из внешних источников (векторных баз).

## T

**Tool (Инструмент)**
Функция, которую агент может вызвать для получения данных или выполнения действия.

**Trigger (Триггер)**
Событие, при наступлении которого запускается агент.

## V

**Vector Database (Векторная БД)**
База данных для хранения и поиска по векторным представлениям текста.

**Vision**
Способность LLM анализировать изображения (например, GPT-4o Vision).

## W

**Workflow**
Последовательность шагов обработки запроса агентом.
