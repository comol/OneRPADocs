# Список ошибок

Коды ошибок и рекомендации по их устранению.

## HTTP коды

| Код | Описание | Решение |
|-----|----------|---------|
| 200 | Успех | — |
| 400 | Неверный запрос | Проверьте формат запроса |
| 401 | Не авторизован | Проверьте API ключ |
| 403 | Доступ запрещён | Проверьте права |
| 404 | Не найден | Проверьте URL |
| 429 | Слишком много запросов | Подождите, проверьте лимиты |
| 500 | Внутренняя ошибка | Смотрите логи |
| 502 | Bad Gateway | Проверьте Proxy |
| 503 | Сервис недоступен | Подождите, перезапустите |
| 504 | Таймаут | Увеличьте таймаут |

## Ошибки LLM провайдеров

### OpenAI

| Ошибка | Причина | Решение |
|--------|---------|---------|
| invalid_api_key | Неверный ключ | Проверьте API ключ |
| insufficient_quota | Нет средств | Пополните баланс |
| rate_limit_exceeded | Превышен лимит | Подождите |
| model_not_found | Модель не найдена | Проверьте имя модели |

### Yandex GPT

| Ошибка | Причина | Решение |
|--------|---------|---------|
| UNAUTHENTICATED | Ошибка авторизации | Обновите IAM токен |
| PERMISSION_DENIED | Нет доступа | Проверьте folder_id |
| RESOURCE_EXHAUSTED | Превышена квота | Подождите |

### Ollama

| Ошибка | Причина | Решение |
|--------|---------|---------|
| connection refused | Сервер недоступен | Запустите Ollama |
| model not found | Модель не загружена | `ollama pull <model>` |

## Ошибки OneAPA

| Код | Описание | Решение |
|-----|----------|---------|
| APA_001 | Агент не найден | Выполните обмен с Proxy |
| APA_002 | Инструмент не найден | Добавьте инструмент в агента |
| APA_003 | Ошибка выполнения инструмента | Смотрите логи 1С |
| APA_004 | Таймаут агента | Увеличьте таймаут |
| APA_005 | Превышен лимит итераций | Проверьте промпт |

## Ошибки 1С

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Объект не найден" | Ссылка на несуществующий объект | Проверьте данные |
| "Недостаточно прав" | Нет роли APA_ОсновнаяРоль | Назначьте роль |
| "Ошибка HTTP" | Проблема с сетью | Проверьте подключение |
