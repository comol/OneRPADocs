# Масштабирование

Руководство по масштабированию OneAPA.

## Стратегии масштабирования

| Стратегия | Описание | Когда использовать |
|-----------|----------|-------------------|
| Вертикальная | Увеличение ресурсов | До 50-100 пользователей |
| Горизонтальная | Добавление инстансов | 100+ пользователей |

## Вертикальное масштабирование

### Proxy-сервер

| Параметр | Было | Стало |
|----------|------|-------|
| CPU | 2 ядра | 4 ядра |
| RAM | 4 ГБ | 8 ГБ |
| Workers | 1 | 4 |

```bash
# Увеличение workers
uvicorn main:app --workers 4 --host 0.0.0.0 --port 9000
```

### Ollama (для локальных моделей)

- Добавьте GPU
- Увеличьте VRAM
- Используйте более быстрый SSD

## Горизонтальное масштабирование

### Архитектура

```
                    ┌─────────────────┐
                    │  Load Balancer  │
                    └────────┬────────┘
                             │
           ┌─────────────────┼─────────────────┐
           ▼                 ▼                 ▼
    ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
    │   Proxy 1   │   │   Proxy 2   │   │   Proxy 3   │
    └─────────────┘   └─────────────┘   └─────────────┘
```

### Docker Swarm

```bash
# Инициализация
docker swarm init

# Создание сервиса
docker service create \
  --name oneapa-proxy \
  --replicas 3 \
  -p 9000:9000 \
  oneapa-proxy:latest

# Масштабирование
docker service scale oneapa-proxy=5
```

### Nginx балансировщик

```nginx
upstream oneapa {
    least_conn;
    server proxy1:9000;
    server proxy2:9000;
    server proxy3:9000;
}

server {
    listen 80;
    location / {
        proxy_pass http://oneapa;
    }
}
```

## Оптимизация

### Кэширование

- Кэшируйте редко меняющиеся данные
- Используйте Redis для сессий

### Асинхронность

- Используйте async инструменты
- Параллельные вызовы LLM

### Выбор модели

| Нагрузка | Модель |
|----------|--------|
| Низкая | GPT-4o (качество) |
| Высокая | GPT-4o-mini (скорость) |
| Очень высокая | Ollama + GPU кластер |

## Мониторинг при масштабировании

- Отслеживайте нагрузку на каждый инстанс
- Настройте автомасштабирование
- Мониторьте latency
