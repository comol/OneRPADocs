# RAG (Retrieval-Augmented Generation)

Руководство по использованию RAG в OneAPA.

## Что такое RAG

**RAG** — технология, позволяющая LLM использовать внешние базы знаний для формирования ответов.

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│    Вопрос       │────►│  Векторный      │────►│  Релевантные    │
│  пользователя   │     │    поиск        │     │   документы     │
└─────────────────┘     └─────────────────┘     └────────┬────────┘
                                                         │
                                                         ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│     Ответ       │◄────│      LLM        │◄────│  Вопрос +       │
│                 │     │                 │     │  Контекст       │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

## Преимущества RAG

| Преимущество | Описание |
|--------------|----------|
| Актуальность | Использование свежих данных |
| Точность | Ответы на основе ваших документов |
| Контроль | Вы определяете источники |
| Прозрачность | Можно увидеть источники ответа |

## Компоненты RAG в OneAPA

### 1. Выгрузка данных

Обработка `APA_ВыгрузкаВВекторнуюБД` — выгружает данные из 1С в векторную БД.

### 2. Модуль APA_RAG

Серверный модуль для поиска в векторной БД.

### 3. Инструмент поиска

Инструмент агента для вызова RAG.

## Настройка RAG

### Шаг 1: Развёртывание векторной БД

**Chroma (рекомендуется для начала):**

```bash
# Docker
docker run -d -p 8000:8000 chromadb/chroma

# Python
pip install chromadb
```

### Шаг 2: Выгрузка данных

1. Откройте обработку "Выгрузка в векторную БД"
2. Укажите адрес БД: `http://localhost:8000`
3. Укажите имя коллекции: `company_docs`
4. Напишите запрос для выбора данных
5. Нажмите "Выгрузить"

### Шаг 3: Создание инструмента

```
Наименование: Поиск в базе знаний
Описание: Ищет информацию в документах компании.
          Используй для вопросов о регламентах, 
          инструкциях и внутренних правилах.

Код:
Запрос = Параметры.Запрос;
Результаты = APA_RAG.НайтиДокументы(
    "http://localhost:8000",
    "company_docs",
    Запрос,
    5
);
Возврат Результаты;

Параметры:
- query (string): Поисковый запрос
```

### Шаг 4: Добавление в агента

1. Откройте агента
2. Добавьте инструмент "Поиск в базе знаний"
3. Сохраните

## Модуль APA_RAG

### Функции

```bsl
// Поиск документов
Функция НайтиДокументы(
    АдресБД,           // URL векторной БД
    Коллекция,         // Имя коллекции
    Запрос,            // Текст запроса
    КоличествоРезультатов = 5
) Экспорт

// Добавление документа
Процедура ДобавитьДокумент(
    АдресБД,
    Коллекция,
    Текст,
    Метаданные = Неопределено
) Экспорт

// Удаление коллекции
Процедура УдалитьКоллекцию(
    АдресБД,
    Коллекция
) Экспорт
```

## Пример использования

### Без RAG

```
Пользователь: Какова процедура оформления командировки?

Агент: Обычно процедура оформления командировки включает...
       (общая информация, может быть неактуальной)
```

### С RAG

```
Пользователь: Какова процедура оформления командировки?

Агент:
📚 Поиск в базе знаний...
Найдено: "Положение о командировках" (стр. 5-7)

Согласно Положению о командировках от 01.01.2025:

1. Заполнить заявку в системе (не позднее 5 дней до выезда)
2. Приложить обоснование командировки
3. Получить согласование руководителя
4. Получить визу отдела кадров
5. Оформить приказ
6. Получить командировочное удостоверение
7. Получить аванс в бухгалтерии

Источник: Положение о командировках, п. 3.1-3.7
```

## Подготовка данных

### Рекомендации

| Аспект | Рекомендация |
|--------|--------------|
| Размер фрагмента | 500-1500 символов |
| Перекрытие | 10-20% от размера |
| Метаданные | Добавляйте источник, дату |
| Качество текста | Очищайте от мусора |

### Пример запроса для выгрузки

```sql
ВЫБРАТЬ
    Наименование КАК Заголовок,
    Содержимое КАК Текст,
    Дата КАК ДатаДокумента,
    "Регламенты" КАК Категория
ИЗ
    Справочник.ВнутренниеДокументы
ГДЕ
    НЕ ПометкаУдаления
    И ТипДокумента = &ТипРегламент
```

## Поддерживаемые векторные БД

| БД | Установка | Примечание |
|----|-----------|------------|
| Chroma | `docker run chromadb/chroma` | Простая, для начала |
| Milvus | `docker-compose` | Масштабируемая |
| Qdrant | `docker run qdrant/qdrant` | Высокая производительность |
| Pinecone | Облачный сервис | Managed решение |

## Устранение проблем

### Плохое качество поиска

1. Улучшите качество текстов
2. Настройте размер фрагментов
3. Добавьте больше данных

### Медленный поиск

1. Оптимизируйте индексы
2. Уменьшите количество результатов
3. Используйте более быструю БД
