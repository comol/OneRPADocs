# Установка 1С конфигурации

Подробная инструкция по установке конфигурации OneAPA в 1С:Предприятие.

## Подготовка

### Что вам понадобится

- Файл конфигурации OneAPA (`.cf`) или файл расширения (`.cfe`)
- Доступ к Конфигуратору 1С
- Права на изменение конфигурации

### Форматы поставки

| Формат | Расширение | Использование |
|--------|------------|---------------|
| **Полная конфигурация** | .cf | Для новых баз или полной замены |
| **Расширение** | .cfe | Для добавления к существующей конфигурации |

## Вариант 1: Новая база данных

### Шаг 1: Создание базы

1. Запустите 1С:Предприятие
2. Нажмите "Добавить"
3. Выберите "Создание новой информационной базы"
4. Выберите "Создание информационной базы без конфигурации"
5. Укажите имя и расположение базы
6. Завершите мастер

### Шаг 2: Загрузка конфигурации

1. Откройте созданную базу в режиме "Конфигуратор"
2. Меню "Конфигурация" → "Загрузить конфигурацию из файла..."
3. Выберите файл `OneAPA.cf`
4. Дождитесь загрузки

### Шаг 3: Обновление базы данных

1. Меню "Конфигурация" → "Обновить конфигурацию базы данных" (F7)
2. Подтвердите изменения
3. Дождитесь обновления

### Шаг 4: Проверка

1. Закройте Конфигуратор
2. Откройте базу в режиме "1С:Предприятие"
3. Проверьте наличие меню "Чат" и справочников

## Вариант 2: Объединение с существующей конфигурацией

### Шаг 1: Резервное копирование

{% hint style="danger" %}
**Обязательно** создайте резервную копию базы данных перед объединением!
{% endhint %}

1. Откройте базу в Конфигураторе
2. Меню "Администрирование" → "Выгрузить информационную базу..."
3. Сохраните файл `.dt`

### Шаг 2: Сравнение и объединение

1. Меню "Конфигурация" → "Сравнить, объединить с конфигурацией из файла..."
2. Выберите файл `OneAPA.cf`
3. Дождитесь анализа

1. Нажмите "Выполнить"
2. Дождитесь завершения объединения
3. Проверьте протокол на наличие ошибок

### Шаг 5: Обновление базы данных

1. Меню "Конфигурация" → "Обновить конфигурацию базы данных" (F7)
2. Изучите список изменений
3. Подтвердите обновление

## Вариант 3: Установка расширения

### Шаг 1: Открытие менеджера расширений

1. Откройте базу в Конфигураторе
2. Меню "Конфигурация" → "Расширения конфигурации..."

### Шаг 2: Добавление расширения

1. Нажмите "Добавить" (зелёный плюс)
2. Выберите файл `OneAPA.cfe`
3. Дождитесь загрузки

### Шаг 3: Настройка расширения

1. Выберите загруженное расширение
2. Установите свойства:
   - Безопасный режим: Нет
   - Защита от опасных действий: Нет (если требуется)

### Шаг 4: Обновление

1. Меню "Конфигурация" → "Обновить конфигурацию базы данных" (F7)
2. Подтвердите изменения

## Настройка прав доступа

### Назначение роли

После установки назначьте роль `APA_ОсновнаяРоль` пользователям:

1. Откройте "Администрирование" → "Пользователи"
2. Откройте карточку пользователя
3. Перейдите на вкладку "Права"
4. Добавьте роль "APA_ОсновнаяРоль"
5. Сохраните

### Состав роли

Роль `APA_ОсновнаяРоль` включает права на:

| Объект | Права |
|--------|-------|
| Справочники APA_* | Чтение, Добавление, Изменение |
| Регистры APA_* | Чтение, Запись |
| Обработки APA_* | Использование |
| Команды APA_* | Использование |

## Устранение проблем

### Ошибка "Объект не найден"

**Причина:** Не все объекты были выбраны при объединении.

**Решение:** Повторите объединение, убедившись, что выбраны все объекты с префиксом `APA_`.

### Конфликт имён объектов

**Причина:** В вашей конфигурации есть объекты с такими же именами.

**Решение:** 
- Переименуйте конфликтующие объекты в вашей конфигурации
- Или используйте расширение вместо объединения

### Ошибка при обновлении базы данных

**Причина:** Несовместимость версий или заблокированные объекты.

**Решение:**
1. Убедитесь, что все пользователи вышли из базы
2. Проверьте режим совместимости конфигурации
3. Изучите текст ошибки

### Не хватает прав

**Причина:** У пользователя нет роли `APA_ОсновнаяРоль`.

**Решение:** Назначьте роль пользователю.

## Обновление конфигурации

### При выходе новой версии

1. Получите новый файл конфигурации
2. Создайте резервную копию базы
3. Выполните сравнение и объединение
4. Обновите базу данных
5. Проверьте работоспособность

### Сохранение пользовательских изменений

Если вы вносили изменения в объекты OneAPA:

1. При объединении выберите "Взять из текущей конфигурации" для изменённых объектов
2. После объединения вручную перенесите свои изменения
