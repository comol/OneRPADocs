# Системные требования

Подробные требования к аппаратному и программному обеспечению для развёртывания OneAPA.

## Сервер 1С:Предприятие

### Аппаратные требования

| Параметр | Минимум | Рекомендуется | Примечание |
|----------|---------|---------------|------------|
| **Процессор** | 2 ядра, 2.0 ГГц | 4+ ядра, 2.5+ ГГц | x64 архитектура |
| **ОЗУ** | 4 ГБ | 8-16 ГБ | Зависит от размера базы |
| **Диск** | 10 ГБ свободно | SSD, 50+ ГБ | SSD критичен для производительности |
| **Сеть** | 100 Мбит/с | 1 Гбит/с | Для связи с Proxy |

### Программные требования

| Компонент | Версия | Примечание |
|-----------|--------|------------|
| **ОС Windows** | Server 2016, 2019, 2022 | Или Windows 10/11 для разработки |
| **ОС Linux** | Astra Linux, Ubuntu 20.04+, CentOS 8+ | С установленным 1С для Linux |
| **1С:Предприятие** | 8.3.20 и выше | Платформа |
| **Совместимость** | 8.3.18 и выше | Режим совместимости конфигурации |

### Лицензирование 1С

- Требуется лицензия 1С:Предприятие
- Серверная лицензия для клиент-серверного режима
- Клиентские лицензии для пользователей

## Требования для Ollama

### NVIDIA GPU

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| **Модель** | GTX 1660 (6 ГБ) | RTX 3090 / A6000 (24 ГБ) |
| **VRAM** | 8 ГБ | 16-24 ГБ |
| **CUDA** | 11.7+ | 12.0+ |
| **Драйвер** | 515+ | Последний |

### Размер моделей

| Модель | Размер | Требуется VRAM |
|--------|--------|----------------|
| Llama 3 8B | ~4.7 ГБ | 8 ГБ |
| Llama 3 70B | ~40 ГБ | 48 ГБ (или CPU) |
| Mistral 7B | ~4 ГБ | 8 ГБ |
| Qwen 2.5 7B | ~4.5 ГБ | 8 ГБ |

{% hint style="warning" %}
Для работы больших моделей без GPU требуется значительный объём ОЗУ (32-128 ГБ), и работа будет существенно медленнее.
{% endhint %}

## Сетевые требования

### Порты

| Порт | Протокол | Назначение | Направление |
|------|----------|------------|-------------|
| **9000** | TCP | Proxy API и Web UI | Входящий |
| **443** | TCP | LLM провайдеры (OpenAI, Yandex) | Исходящий |
| **11434** | TCP | Ollama API | Внутренний |

### Firewall

**Для сервера 1С:**

```bash
# Разрешить исходящие к Proxy
iptables -A OUTPUT -p tcp --dport 9000 -j ACCEPT
```

**Для сервера Proxy:**

```bash
# Разрешить входящие на порт 9000
iptables -A INPUT -p tcp --dport 9000 -j ACCEPT

# Разрешить исходящие к LLM провайдерам
iptables -A OUTPUT -p tcp --dport 443 -j ACCEPT
```

### Пропускная способность

| Сценарий | Минимум | Рекомендуется |
|----------|---------|---------------|
| 1С ↔ Proxy | 10 Мбит/с | 100 Мбит/с |
| Proxy ↔ LLM (cloud) | 5 Мбит/с | 20+ Мбит/с |
| Proxy ↔ Ollama | 100 Мбит/с | 1 Гбит/с |

## Проверка соответствия

### Скрипт проверки (Python)

```python
import sys
import platform

print(f"Python: {sys.version}")
print(f"ОС: {platform.system()} {platform.release()}")
print(f"Архитектура: {platform.machine()}")

# Проверка версии Python
major, minor = sys.version_info[:2]
if (major, minor) >= (3, 11):
    print("✅ Версия Python подходит")
else:
    print("❌ Требуется Python 3.11 или выше")
```

### Проверка Docker

```bash
# Версия Docker
docker --version

# Проверка работы
docker run hello-world
```

### Проверка GPU (для Ollama)

```bash
# NVIDIA GPU
nvidia-smi

# CUDA
nvcc --version
```
