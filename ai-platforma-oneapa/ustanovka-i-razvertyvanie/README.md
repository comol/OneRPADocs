## Варианты развёртывания

### Вариант 1: Минимальный (разработка/тестирование)

```
┌─────────────────────────────────────────────────┐
│              Один сервер                         │
│                                                  │
│  ┌─────────────┐    ┌─────────────────────────┐ │
│  │    1С       │    │   Proxy (Python/Docker) │ │
│  │  + OneAPA   │◄──►│                         │ │
│  └─────────────┘    └─────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

**Подходит для:**
- Разработки и тестирования
- Небольших команд (до 10 пользователей)
- Ознакомления с системой

### Вариант 2: Стандартный (малый/средний бизнес)

```
┌─────────────────────────────────────────────────────────────┐
│                      Локальная сеть                          │
│                                                              │
│  ┌─────────────────┐          ┌───────────────────────────┐ │
│  │   Сервер 1С     │          │   Сервер Proxy            │ │
│  │                 │◄────────►│   (Docker)                │ │
│  │   + OneAPA      │          │                           │ │
│  └─────────────────┘          └─────────────┬─────────────┘ │
│                                             │                │
└─────────────────────────────────────────────┼────────────────┘
                                              │
                                    ┌─────────┴─────────┐
                                    │   LLM Provider    │
                                    │   (Cloud/Ollama)  │
                                    └───────────────────┘
```

**Подходит для:**
- Производственной эксплуатации
- Команд 10-100 пользователей
- Требований к отказоустойчивости

### Вариант 3: Enterprise (крупные организации)

```
┌─────────────────────────────────────────────────────────────────────┐
│                          Продуктивная среда                          │
│                                                                      │
│  ┌───────────────────┐    ┌─────────────────────────────────────┐   │
│  │  Кластер 1С       │    │        Балансировщик                │   │
│  │  + OneAPA         │◄──►│                                     │   │
│  │  (несколько       │    │   ┌─────────┐  ┌─────────┐          │   │
│  │   серверов)       │    │   │ Proxy 1 │  │ Proxy 2 │  ...     │   │
│  └───────────────────┘    │   └─────────┘  └─────────┘          │   │
│                           └─────────────────────────────────────┘   │
│                                                                      │
│  ┌───────────────────┐    ┌─────────────────────────────────────┐   │
│  │  Мониторинг       │    │   LLM (Ollama cluster /             │   │
│  │  + Логирование    │    │        Cloud providers)             │   │
│  └───────────────────┘    └─────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

**Подходит для:**
- Крупных организаций (100+ пользователей)
- Высоких требований к доступности
- Масштабируемой нагрузки

## Этапы установки

### Этап 1: Подготовка

1. Проверьте [системные требования](sistemnye-trebovaniya.md)
2. Выберите вариант развёртывания
3. Подготовьте инфраструктуру (серверы, сеть)
4. Получите лицензию OneAPA

### Этап 2: Установка 1С

1. [Установите конфигурацию](ustanovka-1c-konfiguratsii.md)
2. Настройте пользователей и права

### Этап 3: Установка Proxy

1. Выберите способ установки:
   - [Docker](nastrojka-docker.md) (рекомендуется)
   - [Python](ustanovka-proxy-servera.md)
2. Настройте переменные окружения
3. Запустите сервер

### Этап 4: Интеграция

1. Настройте связь между 1С и Proxy
2. Выполните первичную синхронизацию
3. Проверьте работоспособность

### Этап 5: Настройка LLM

1. Выберите провайдера LLM
2. Получите API ключи
3. Создайте модели в системе

## Рекомендации по выбору

### Выбор ОС для Proxy

| ОС | Рекомендация | Примечание |
|----|--------------|------------|
| **Linux (Ubuntu/Debian)** | ⭐⭐⭐⭐⭐ | Лучший выбор для production |
| **Windows Server** | ⭐⭐⭐⭐ | Если вся инфраструктура на Windows |
| **Windows 10/11** | ⭐⭐⭐ | Только для разработки |
| **macOS** | ⭐⭐ | Только для разработки |

### Выбор способа установки Proxy

| Способ | Плюсы | Минусы |
|--------|-------|--------|
| **Docker** | Простота, изоляция, воспроизводимость | Требует Docker |
| **Python** | Гибкость, отладка | Управление зависимостями |

### Выбор LLM провайдера

| Критерий | Cloud (OpenAI, Yandex) | On-Premise (Ollama) |
|----------|------------------------|---------------------|
| Качество | Высокое | Зависит от модели |
| Стоимость | Оплата за токены | Стоимость оборудования |
| Конфиденциальность | Данные уходят в облако | Полная изоляция |
| Настройка | Простая | Требует ресурсов |

## Время установки

| Вариант | Ориентировочное время |
|---------|----------------------|
| Минимальный | 30 минут — 1 час |
| Стандартный | 2-4 часа |
| Enterprise | 1-3 дня |
