# AI платформа OneAPA

{% hint style="info" %}
**OneAPA** (Agentic Process Automation) — платформа low-code разработки ИИ агентов на базе 1С:Предприятие с поддержкой множества LLM провайдеров и On-Premise развёртыванием.
{% endhint %}

## Что такое OneAPA?

OneAPA — это платформа для создания и управления автономными ИИ агентами, которые способны выполнять бизнес-задачи, взаимодействуя с данными и системами вашей организации. Агенты работают непосредственно в среде 1С:Предприятие, используя возможности современных языковых моделей (LLM).

### Ключевые преимущества

| Преимущество            | Описание                                                                                                 |
| ----------------------- | -------------------------------------------------------------------------------------------------------- |
| **Low-code разработка** | Создавайте агентов без глубоких знаний программирования — достаточно задать промпт и выбрать инструменты |
| **On-Premise**          | Все данные остаются в вашей инфраструктуре — никакие конфиденциальные сведения не передаются наружу      |
| **Множество LLM**       | Поддержка Yandex GPT, OpenAI, OpenRouter, Ollama (локальные модели), Sber                                |
| **Интеграция с 1С**     | Агенты работают с данными 1С напрямую, используя встроенные механизмы платформы                          |
| **MCP поддержка**       | Встроенный MCP сервер и клиент для интеграции с внешними инструментами                                   |
| **Интеграция с OneRPA** | Запуск роботов OneRPA как инструментов агента                                                            |

## Чем ИИ агенты лучше традиционных систем?

### Работа в условиях неопределённости

Даже если какое-то поведение не заложено изначально и возникла нештатная ситуация, ИИ агент может её обработать. Если у агента достаточно данных для корректной реакции — результат вас приятно удивит.

### Адаптивность и обучаемость

ИИ агент запоминает информацию о пользователе, учитывает контекст, учитывает доступные данные о персоналии. Результат может отличаться по одному запросу для разных категорий сотрудников.

### Работа с произвольными данными

ИИ агент может обработать любой запрос с данными в любом формате. Нет необходимости использования строгих форматов и протоколов. Это существенно упрощает интерфейс и использование системы.

### Автономность

Классические системы требуют множества доработок и расширений под различные ситуации. ИИ агенты не требуют постоянного участия ИТ-специалистов. Качественный ИИ агент может решать множество задач самостоятельно.

## Системные требования

**Минимальные требования:**

* 1С:Предприятие 8.3.20 и выше
* Windows Server 2016+ / Linux
* Python 3.11+ (для Proxy)
* 8 ГБ ОЗУ (рекомендуется 16 ГБ)
* Доступ к LLM провайдеру (или локальная модель Ollama)
