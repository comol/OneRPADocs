## Выбор провайдера

### Для максимального качества

**Рекомендация:** OpenAI GPT-4o или OpenRouter с Claude 3

- Лучшие результаты для сложных задач
- Поддержка изображений (Vision)
- Reasoning модели (o1, o3)

### Для конфиденциальности

**Рекомендация:** Ollama

- Данные не покидают вашу сеть
- Полный контроль над моделью
- Соответствие ФЗ-152

### Для экономии

**Рекомендация:** Ollama или OpenAI GPT-4o-mini

- Ollama: бесплатно (только оборудование)
- GPT-4o-mini: низкая стоимость за токен

### Для российских требований

**Рекомендация:** Yandex GPT или Sber GigaChat

- Российские провайдеры
- Хранение данных в РФ
- Соответствие законодательству

## Настройка модели

### Общий порядок

1. Получите доступ к провайдеру (регистрация, API ключ)
2. Создайте модель в справочнике `APA_Модели`
3. Заполните параметры подключения
4. Протестируйте модель

### Параметры модели

| Поле | Описание |
|------|----------|
| **Наименование** | Понятное название |
| **Провайдер** | Выбор из перечисления |
| **Ключ** | API ключ или токен |
| **Каталог** | Название модели |
| **URL** | Для локальных провайдеров |

## Особенности моделей

### Vision модели

Модели с поддержкой изображений:
- OpenAI: GPT-4o, GPT-4-turbo
- Ollama: llava, bakllava

```
Пользователь: [прикрепляет скриншот]
              "Что на этом изображении?"

Агент: "На изображении показана ошибка подключения..."
```

### Reasoning модели

Модели с улучшенными способностями к рассуждению:
- OpenAI: o1, o3

```
Пользователь: "Проанализируй финансовые показатели за квартал"

Агент: [использует цепочку рассуждений]
       "1. Анализирую выручку...
        2. Сравниваю с предыдущим периодом...
        3. Вывод: ..."
```
