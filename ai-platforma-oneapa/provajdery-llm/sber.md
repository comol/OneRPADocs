# Sber GigaChat

Настройка Sber GigaChat в качестве LLM провайдера для OneAPA.

## Обзор

**GigaChat** — языковая модель от Сбера для работы с русским языком.

### Преимущества

| Преимущество | Описание |
|--------------|----------|
| Русский язык | Оптимизирован для русского |
| Российский провайдер | Хранение данных в РФ |
| Интеграция | Экосистема Сбера |

### Ограничения

| Ограничение | Описание |
|-------------|----------|
| Нет Vision | Не поддерживает изображения |
| Доступность | Ограниченный доступ |

## Получение доступа

### Шаг 1: Регистрация

1. Перейдите на [developers.sber.ru](https://developers.sber.ru/)
2. Зарегистрируйтесь или войдите через Сбер ID
3. Подтвердите данные

### Шаг 2: Подключение API

1. Создайте проект
2. Подключите GigaChat API
3. Примите условия использования

### Шаг 3: Получение API ключа

1. Перейдите в раздел "Ключи API"
2. Создайте новый ключ
3. Скопируйте ключ

## Настройка в OneAPA

### Создание модели

| Поле | Значение |
|------|----------|
| Наименование | Sber GigaChat |
| Провайдер | Sber |
| Ключ | (API ключ) |
| Каталог | GigaChat |
| URL | (пусто) |

### Пример

```
Наименование: Sber GigaChat
Провайдер: Sber
Ключ: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Каталог: GigaChat
URL: 
```

## Устранение проблем

### Ошибка авторизации

| Причина | Решение |
|---------|---------|
| Неверный ключ | Проверьте API ключ |
| Ключ деактивирован | Создайте новый ключ |
| Нет доступа | Подключите GigaChat API в личном кабинете |

### Ошибка квоты

| Причина | Решение |
|---------|---------|
| Превышен лимит | Подождите или увеличьте квоту |
| Недостаточно средств | Пополните баланс |

### Медленные ответы

| Причина | Решение |
|---------|---------|
| Перегрузка сервиса | Повторите позже |
| Большой запрос | Уменьшите размер контекста |
