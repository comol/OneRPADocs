## Роли и права в 1С

### Роль APA_ОсновнаяРоль

Роль `APA_ОсновнаяРоль` предоставляет доступ ко всем объектам OneAPA.

#### Права роли

| Объект | Чтение | Добавление | Изменение | Удаление |
|--------|--------|------------|-----------|----------|
| Справочники APA_* | ✅ | ✅ | ✅ | ✅ |
| Регистры APA_* | ✅ | ✅ | ✅ | ✅ |
| Обработки APA_* | ✅ | - | - | - |
| Команды APA_* | ✅ | - | - | - |

#### Назначение роли

1. Откройте "Администрирование" → "Пользователи"
2. Выберите пользователя
3. Перейдите на вкладку "Права"
4. Добавьте роль "APA_ОсновнаяРоль"

### Разграничение прав

Для ограничения доступа создайте дополнительные роли:

| Роль | Описание | Права |
|------|----------|-------|
| APA_Пользователь | Только работа с чатом | Чтение справочников, использование чата |
| APA_Разработчик | Создание агентов | + Добавление/изменение агентов |
| APA_Администратор | Полный доступ | Все права |

## Доступ к агентам

### Табличная часть "Пользователи"

В справочнике "Агенты" можно ограничить доступ через табличную часть "Пользователи".

```
┌─────────────────────────────────────────────────────────────┐
│  Агент: Финансовый консультант                              │
├─────────────────────────────────────────────────────────────┤
│  [Основное] [Инструменты] [MCP] [Пользователи]             │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Пользователи с доступом к агенту:                          │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ Иванов И.И. (Главный бухгалтер)                        │  │
│  │ Петрова А.С. (Финансовый директор)                     │  │
│  │ Сидоров К.М. (Экономист)                               │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                              │
│  ⓘ Если список пуст — агент доступен всем пользователям    │
└─────────────────────────────────────────────────────────────┘
```

### Правила доступа

| Состояние списка | Доступ |
|------------------|--------|
| Список пуст | Агент доступен всем |
| Есть пользователи | Только указанным пользователям |

## Доступность инструментов

### Табличная часть "Доступность"

В справочнике "Инструменты" можно ограничить, кто может использовать инструмент.

```
┌─────────────────────────────────────────────────────────────┐
│  Инструмент: Просмотр зарплаты сотрудников                  │
├─────────────────────────────────────────────────────────────┤
│  [Основное] [Параметры] [Доступность]                      │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Пользователи с доступом:                                    │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ HR_Менеджер                                            │  │
│  │ Главный_бухгалтер                                      │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### Контекстная доступность

Агент будет использовать только те инструменты, которые доступны текущему пользователю:

```
Пользователь: Менеджер по продажам

Доступные инструменты:
✅ Поиск клиента
✅ Создание заказа
✅ Проверка остатков

Недоступные инструменты:
❌ Просмотр зарплаты
❌ Изменение цен
❌ Удаление документов
```

## Безопасность API ключей

### Хранение ключей

{% hint style="danger" %}
Никогда не храните API ключи в коде или открытых файлах!
{% endhint %}

**Рекомендации:**

| Способ | Безопасность | Удобство |
|--------|--------------|----------|
| В справочнике 1С | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| Переменные окружения | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| Секреты (Vault) | ⭐⭐⭐⭐⭐ | ⭐⭐ |

### Ротация ключей

1. Регулярно обновляйте API ключи
2. Удаляйте неиспользуемые ключи
3. Мониторьте использование ключей

## Лицензионный ключ

### Назначение

Лицензионный ключ (`LICENSE_KEY`) активирует Proxy-сервер.

### Настройка

**Docker:**

```bash
docker run -e LICENSE_KEY=your_key oneapa-proxy
```

**Python:**

```bash
export LICENSE_KEY=your_key
python main.py
```

### Безопасность ключа

- Не передавайте ключ по открытым каналам
- Используйте секреты Docker/Kubernetes
- Не включайте в систему контроля версий

## SSL/TLS

### Настройка HTTPS

Для production обязательно используйте HTTPS:

```nginx
server {
    listen 443 ssl;
    server_name oneapa.company.local;
    
    ssl_certificate /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;
    
    location / {
        proxy_pass http://proxy:9000;
    }
}
```

### Самоподписанный сертификат

Для тестирования:

```bash
openssl req -x509 -nodes -days 365 \
  -newkey rsa:2048 \
  -keyout key.pem \
  -out cert.pem \
  -subj "/CN=oneapa.local"
```

## On-Premise и конфиденциальность

### Ollama для полной изоляции

При использовании Ollama данные не покидают вашу инфраструктуру:

```
┌─────────────────────────────────────────────────────────────┐
│                   ИЗОЛИРОВАННАЯ СРЕДА                        │
│                                                              │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐      │
│  │    1С       │───►│   Proxy     │───►│   Ollama    │      │
│  └─────────────┘    └─────────────┘    └─────────────┘      │
│                                                              │
│           ❌ НЕТ ДОСТУПА К ИНТЕРНЕТУ ❌                      │
│                                                              │
│  ✅ Данные остаются внутри сети                             │
│  ✅ Полный контроль над моделью                             │
│  ✅ Соответствие требованиям ФЗ-152                         │
└─────────────────────────────────────────────────────────────┘
```

### Что передаётся облачным провайдерам

При использовании OpenAI, Yandex и других облачных провайдеров:

| Данные | Передаются |
|--------|------------|
| Текст сообщений пользователя | ✅ Да |
| Прикреплённые файлы | ✅ Да |
| Результаты инструментов | ✅ Да |
| Данные из базы 1С | ⚠️ Только если запрошены агентом |

{% hint style="warning" %}
Тщательно настраивайте инструменты, чтобы не передавать лишние данные провайдерам.
{% endhint %}

## Логирование и аудит

### Регистр APA_ЛогИнструментов

Все вызовы инструментов записываются:

| Поле | Описание |
|------|----------|
| Инструмент | Какой инструмент вызван |
| Дата | Когда вызван |
| Состояние | Успешно/Ошибка |
| Результат | Что вернул |

### Мониторинг подозрительной активности

Отслеживайте:

- Частые ошибки инструментов
- Нетипичное время использования
- Попытки доступа к закрытым данным

## Чек-лист безопасности

### Минимальный

- [ ] Роль APA_ОсновнаяРоль назначена только нужным пользователям
- [ ] API ключи хранятся в справочнике 1С
- [ ] Proxy-сервер доступен только из внутренней сети

### Рекомендуемый

- [ ] Настроен HTTPS для Proxy
- [ ] Ограничен доступ к чувствительным агентам
- [ ] Ограничен доступ к чувствительным инструментам
- [ ] Включено логирование
- [ ] Настроен мониторинг

### Максимальный

- [ ] Используется Ollama (On-Premise LLM)
- [ ] Сеть полностью изолирована
- [ ] API ключи в системе секретов (Vault)
- [ ] Регулярная ротация ключей
- [ ] Аудит использования
