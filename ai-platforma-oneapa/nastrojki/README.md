## Доступ к настройкам

### Команда "Настройки"

Для открытия формы настроек используйте:

- Меню "Панель действий" → "Настройки"
- Или выполните команду `APA_Настройки`

## Основные параметры

### Обязательные настройки

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| URL Proxy сервера | Адрес Proxy-сервера | `http://localhost:9000` |
| Лицензионный ключ | Ключ активации | - |

### Настройки производительности

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| Таймаут LLM | Время ожидания ответа LLM | 900 сек |
| Таймаут инструментов | Время выполнения инструмента | 900 сек |
| Макс. итераций | Лимит циклов агента | 15 |

### Настройки логирования

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| Логировать инструменты | Запись в регистр | Да |
| Уровень логирования | DEBUG/INFO/WARNING/ERROR | INFO |

## Применение настроек

{% hint style="warning" %}
После изменения настроек необходимо выполнить синхронизацию с Proxy-сервером командой "Выполнить обмен с Proxy".
{% endhint %}

### Порядок применения

1. Измените настройки в форме
2. Сохраните изменения
3. Выполните команду `APA_ВыполнитьОбменСПрокси`
4. Проверьте работоспособность

## Рекомендации

### Для разработки

- URL Proxy: `http://localhost:9000`
- Подробное логирование: включено
- Таймауты: стандартные

### Для production

- URL Proxy: `https://proxy.company.local`
- Подробное логирование: отключено
- Таймауты: увеличены при необходимости
