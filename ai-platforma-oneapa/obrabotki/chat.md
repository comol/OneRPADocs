# Обработка "Чат"

Обработка `APA_Chat` предоставляет интерфейс для взаимодействия с ИИ агентами.

## Назначение

Чат — основной способ взаимодействия пользователей с агентами:
- Отправка текстовых сообщений
- Получение ответов от агента
- Просмотр истории диалога
- Прикрепление файлов

### Элементы управления

| Элемент | Назначение |
|---------|------------|

## Открытие чата

### Способ 1: Команда

Выполните команду `APA_Чат` через:
- Командную строку 1С
- Поиск по командам

### Способ 2: Меню

Панель навигации → Чат

### Способ 3: Горячая клавиша

Если настроена — используйте назначенное сочетание клавиш.

## Работа с чатом

### Отправка сообщения

1. Выберите агента (если несколько)
2. Введите текст в поле ввода
3. Нажмите "Отправить" или Enter

### Прикрепление файлов

1. Нажмите "Прикрепить"
2. Выберите файл
3. Файл будет отправлен вместе с сообщением

**Поддерживаемые форматы:**
- Изображения: JPG, PNG, GIF (для Vision моделей)
- Документы: PDF, DOCX, XLSX, TXT
- Данные: JSON, XML, CSV

### Выбор агента

Если в системе несколько агентов:

1. Используйте выпадающий список "Агент"
2. Или позвольте системе выбрать автоматически

**Автоматический выбор:**
- LLM анализирует ваш запрос
- Сравнивает с описаниями агентов
- Выбирает наиболее подходящего

### Просмотр истории

История диалога отображается в основной области:
- Ваши сообщения
- Ответы агента
- Индикаторы использования инструментов

## Индикаторы

### Использование инструментов

```
📊 Использую инструмент: Получить остаток отпуска
```

Показывает, что агент вызывает инструмент для получения данных.

### Ожидание ответа

```
⏳ Агент думает...
```

Показывает, что запрос обрабатывается.

### Ошибка

```
❌ Ошибка: Не удалось подключиться к LLM
```

Показывает информацию об ошибке.

## Контекст диалога

### Сохранение контекста

Агент помнит предыдущие сообщения в рамках сессии:

```
Вы: Меня зовут Иван
Агент: Приятно познакомиться, Иван!

Вы: Как меня зовут?
Агент: Вас зовут Иван.
```

### Размер контекста

Количество сообщений в контексте ограничено настройкой `APA_МаксСообщенийКонтекста` (по умолчанию 20).

### Новый диалог

Для начала нового диалога:
- Закройте и откройте чат заново
- Или обновите страницу (Web UI)

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Enter | Отправить сообщение |
| Ctrl+Enter | Новая строка |
| Esc | Закрыть чат |

## Устранение проблем

### Сообщение не отправляется

1. Проверьте подключение к Proxy
2. Убедитесь, что агент активен
3. Проверьте настройки модели

### Долгое ожидание ответа

1. Проверьте таймауты в настройках
2. Проверьте скорость сети
3. Попробуйте более быструю модель

### Агент не использует инструменты

1. Убедитесь, что инструменты добавлены в агента
2. Проверьте описания инструментов
3. Выполните синхронизацию с Proxy

### Ошибка при прикреплении файла

1. Проверьте размер файла
2. Проверьте формат файла
3. Убедитесь, что модель поддерживает файлы
