# Обработки

Раздел описывает обработки конфигурации OneAPA.

## Список обработок

| Обработка | Назначение |
|-----------|------------|
| [Чат](chat.md) | Интерфейс для общения с агентами |
| [Выгрузка в векторную БД](vygruzka-v-vektornuyu-bd.md) | Выгрузка данных для RAG |

## Назначение обработок

### APA_Chat — Чат

Основной пользовательский интерфейс для взаимодействия с ИИ агентами.

- Отправка сообщений агенту
- Просмотр истории диалога
- Прикрепление файлов
- Выбор агента

### APA_ВыгрузкаВВекторнуюБД — Выгрузка в векторную БД

Инструмент для работы с RAG (Retrieval-Augmented Generation).

- Выгрузка данных 1С в векторную базу
- Настройка коллекций
- Управление индексами

### APA_ВыгрузкаЗагрузкаАгентов — Экспорт/импорт

Перенос конфигураций агентов между информационными базами.

- Экспорт агентов в файл
- Импорт агентов из файла
- Сохранение настроек, инструментов, промптов

## Доступ к обработкам

### Через команды

| Обработка | Команда |
|-----------|---------|
| Чат | `APA_Чат` |
| Настройки | `APA_Настройки` |

### Через меню

- Панель навигации → Чат
- Панель действий → Настройки
