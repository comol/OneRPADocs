## Общий подход к диагностике

### 1. Определите компонент

```
┌─────────────────────────────────────────────────────────────┐
│                    ДИАГНОСТИКА                               │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Агент не отвечает?                                          │
│       │                                                      │
│       ├── Proxy недоступен? → Ошибки подключения            │
│       │                                                      │
│       ├── LLM возвращает ошибку? → Ошибки LLM               │
│       │                                                      │
│       └── Инструмент не работает? → Ошибки инструментов     │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 2. Проверьте логи

- Логи Proxy: `docker logs oneapa-proxy`
- Логи 1С: регистр APA_ЛогИнструментов

### 3. Изолируйте проблему

- Работает ли health check?
- Работают ли другие агенты?
- Работает ли агент без инструментов?

## Быстрая диагностика

| Симптом | Вероятная причина | Решение |
|---------|-------------------|---------|
| Нет ответа | Proxy не запущен | Запустите Proxy |
| Таймаут | Медленный LLM | Увеличьте таймаут |
| 401 ошибка | Неверный API ключ | Проверьте ключ |
| Агент не найден | Не синхронизировано | Обмен с Proxy |

## Инструменты диагностики

### Health Check

```bash
curl http://proxy:9000/health
```

### Тест подключения к LLM

Создайте простого агента без инструментов и отправьте "Привет".

### Проверка инструмента

Вызовите инструмент напрямую через код 1С.
