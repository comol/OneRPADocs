# FAQ

Часто задаваемые вопросы о OneAPA.

## Общие вопросы

### Что такое OneAPA?

OneAPA — платформа low-code разработки ИИ агентов на базе 1С:Предприятие с поддержкой множества LLM провайдеров.

### Какие LLM провайдеры поддерживаются?

- OpenAI (GPT-4o, o1, o3)
- Yandex GPT
- OpenRouter (множество моделей)
- Ollama (локальные модели)
- Sber GigaChat

### Можно ли работать без интернета?

Да, при использовании Ollama все компоненты работают локально.

## Установка

### Какая версия 1С требуется?

1С:Предприятие 8.3.20 и выше.

### Можно ли установить на Linux?

Да, Proxy-сервер работает на любой ОС. 1С должен быть установлен на поддерживаемой платформе.

### Нужен ли GPU для Ollama?

Рекомендуется, но не обязательно. Без GPU модели работают на CPU (медленнее).

## Настройка

### Как часто обновлять IAM токен Yandex?

Каждые 12 часов. Рекомендуется настроить автоматическое обновление.

### Сколько агентов можно создать?

Ограничений нет. Количество зависит от ваших задач.

### Как ограничить доступ к агенту?

Добавьте пользователей на вкладку "Пользователи" агента. Пустой список означает доступ для всех.

## Разработка

### Как создать инструмент?

1. Справочник "Инструменты" → Создать
2. Напишите описание
3. Напишите код на 1С
4. Добавьте параметры
5. Добавьте инструмент в агента

### Почему агент не использует инструмент?

- Инструмент не добавлен в агента
- Не выполнен обмен с Proxy
- Плохое описание инструмента
- LLM не понимает когда использовать

### Как улучшить качество ответов?

- Используйте более мощную модель (GPT-4o)
- Улучшите системный промпт
- Добавьте примеры в промпт
- Используйте RAG для базы знаний

## Проблемы

### Агент не отвечает

1. Проверьте health check: `curl http://proxy:9000/health`
2. Проверьте логи: `docker logs oneapa-proxy`
3. Проверьте настройки модели
4. Выполните обмен с Proxy

### Ошибка 401

Неверный API ключ. Проверьте ключ в настройках модели.

### Таймаут

1. Увеличьте таймаут в настройках
2. Используйте более быструю модель
3. Упростите запрос

### Инструмент возвращает ошибку

1. Проверьте регистр APA_ЛогИнструментов
2. Найдите текст ошибки
3. Исправьте код инструмента

## Безопасность

### Куда уходят данные?

При использовании облачных провайдеров (OpenAI, Yandex) данные передаются им. При использовании Ollama — данные остаются локально.

### Как защитить API ключи?

- Храните в справочнике 1С (не в коде)
- Используйте переменные окружения для Proxy
- Не публикуйте в репозиториях

### Соответствует ли OneAPA ФЗ-152?

При использовании Ollama (On-Premise) и хранении данных в РФ — да.

## Производительность

### Сколько пользователей поддерживается?

Зависит от оборудования и провайдера. Ориентировочно:
- 1 инстанс Proxy: 10-50 одновременных пользователей
- Кластер: 100+ пользователей

### Как ускорить ответы?

- Используйте более быструю модель (GPT-4o-mini)
- Оптимизируйте инструменты
- Добавьте ресурсы (CPU, RAM)
- Масштабируйте горизонтально
