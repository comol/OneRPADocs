# Ошибки LLM

Диагностика и устранение проблем с LLM провайдерами.

## Общие ошибки

### 401 Unauthorized

**Причина:** Неверный API ключ

**Решение:**
1. Проверьте API ключ в справочнике "Модели"
2. Убедитесь, что ключ актуален
3. Создайте новый ключ при необходимости

### 429 Too Many Requests

**Причина:** Превышен лимит запросов

**Решение:**
1. Подождите и повторите
2. Увеличьте tier (пополнив счёт)
3. Используйте rate limiting

### 500 Internal Server Error

**Причина:** Ошибка на стороне провайдера

**Решение:**
1. Подождите несколько минут
2. Проверьте статус провайдера
3. Попробуйте другую модель

### Timeout

**Причина:** Превышено время ожидания

**Решение:**
1. Увеличьте таймаут в настройках
2. Используйте более быструю модель
3. Упростите запрос

## OpenAI

### Ошибка "Invalid API key"

```
Проверьте:
- Ключ начинается с "sk-"
- Ключ не деактивирован
- Баланс положительный
```

### Ошибка "Model not found"

```
Проверьте:
- Правильное имя модели (gpt-4o, не gpt4o)
- Доступ к модели (некоторые требуют одобрения)
```

## Yandex GPT

### Ошибка авторизации

```
Проверьте:
- IAM токен не истёк (срок 12 часов)
- Правильный folder_id
- Сервис активирован в каталоге
```

### Обновление IAM токена

```bash
yc iam create-token
```

## Ollama

### Ошибка подключения

```
Проверьте:
- Ollama запущен: ollama serve
- Правильный URL: http://localhost:11434
- Порт не занят
```

### Модель не найдена

```bash
# Проверьте загруженные модели
ollama list

# Загрузите модель
ollama pull llama3
```

## Диагностика

### Тест подключения

```bash
# OpenAI
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer sk-..."

# Ollama
curl http://localhost:11434/api/tags
```

### Проверка в логах

```bash
docker logs oneapa-proxy | grep -i "error\|exception"
```
