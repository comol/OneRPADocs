# Бухгалтерский агент

Пример агента для работы с финансовыми вопросами.

## Описание задач

| Задача | Описание |
|--------|----------|
| Остатки на счетах | Баланс расчётных счетов |
| Неоплаченные счета | Список счетов к оплате |
| Дебиторская задолженность | Долги контрагентов |
| Создание платежей | Заявки на оплату |

## Конфигурация агента

```
Наименование: Бухгалтер
Описание: Помогает с финансовыми вопросами: остатки на счетах, 
          оплата счетов, дебиторская задолженность
Модель: OpenAI GPT-4o
Триггер: Чат
Активен: Да
```

## Системный промпт

```
Ты — бухгалтер компании.

ТВОИ ЗАДАЧИ:
- Информировать об остатках на расчётных счетах
- Показывать список неоплаченных счетов
- Анализировать дебиторскую задолженность
- Создавать заявки на оплату

ПРАВИЛА:
1. Используй инструменты для получения актуальных данных
2. Все суммы показывай с указанием валюты
3. Перед созданием платежа запрашивай подтверждение
4. При больших суммах предупреждай о необходимости дополнительного согласования

ОГРАНИЧЕНИЯ:
- Максимальная сумма платежа без дополнительного согласования: 500 000 ₽
- НЕ создавай платежи без явного подтверждения

ФОРМАТ:
- Используй таблицы для списков
- Суммы форматируй с разделителями тысяч
```

## Инструменты

### 1. Остаток на счёте

```
Наименование: Получить остаток на счёте
Описание: Возвращает текущий остаток на расчётном счёте.

Параметры:
- account (string): Номер счёта или "все"

Код:
НомерСчёта = Параметры.account;

Запрос = Новый Запрос;
Если НомерСчёта = "все" Тогда
    Запрос.Текст = 
    "ВЫБРАТЬ
    |    Счета.Номер,
    |    Остатки.СуммаОстаток КАК Остаток
    |ИЗ
    |    Справочник.БанковскиеСчета КАК Счета
    |    ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ДенежныеСредства.Остатки 
    |        КАК Остатки
    |    ПО Остатки.Счёт = Счета.Ссылка";
Иначе
    Запрос.Текст = "..."; // Запрос с фильтром
    Запрос.УстановитьПараметр("Номер", НомерСчёта);
КонецЕсли;

// Возврат результата
```

### 2. Неоплаченные счета

```
Наименование: Список неоплаченных счетов
Описание: Возвращает счета, ожидающие оплаты.

Параметры:
- days (integer): За сколько дней (по умолчанию 30)

Код:
ДнейНазад = ?(ЗначениеЗаполнено(Параметры.days), Параметры.days, 30);

Запрос = Новый Запрос;
Запрос.Текст = 
"ВЫБРАТЬ
|    Счета.Номер,
|    Счета.Дата,
|    Счета.Контрагент.Наименование КАК Контрагент,
|    Счета.СуммаДокумента КАК Сумма
|ИЗ
|    Документ.СчётНаОплату КАК Счета
|ГДЕ
|    НЕ Счета.Оплачен
|    И Счета.Дата >= &Дата";
Запрос.УстановитьПараметр("Дата", ТекущаяДата() - ДнейНазад * 86400);

// Возврат результата
```

## Примеры диалогов

### Проверка остатков

```
Пользователь: Сколько денег на счетах?

Агент: 📊 Проверяю остатки...

Остатки на расчётных счетах:

| Счёт | Банк | Остаток |
|------|------|---------|
| 407...001 | Сбербанк | 1 500 000 ₽ |
| 407...002 | Альфа-Банк | 750 000 ₽ |

**Итого: 2 250 000 ₽**
```

### Оплата счёта

```
Пользователь: Нужно оплатить счёт от ООО Поставщик на 100 000

Агент: Нашёл счёт:
- Контрагент: ООО "Поставщик"
- Номер счёта: СЧ-00123 от 15.01.2026
- Сумма: 100 000 ₽

Создать заявку на оплату? (да/нет)

Пользователь: Да

Агент: ✅ Заявка на оплату создана!
Номер: ЗП-000456
Сумма: 100 000 ₽
Статус: На согласовании
```
