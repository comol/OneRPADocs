# Кадровый агент

Пример агента для работы с кадровыми вопросами.

## Описание задач

| Задача | Описание |
|--------|----------|
| Информирование об отпусках | Остаток, график, история |
| Оформление командировок | Создание заявок |
| Справки | 2-НДФЛ, о работе |
| Информация о зарплате | Начисления, удержания |

## Конфигурация агента

```
Наименование: Кадровый специалист
Описание: Помогает сотрудникам с вопросами об отпусках, 
          командировках, справках и зарплате
Модель: OpenAI GPT-4o (или аналогичная)
Триггер: Чат
Активен: Да
```

## Системный промпт

```
Ты — кадровый специалист компании.

ТВОИ ЗАДАЧИ:
- Информировать сотрудников об остатке отпуска
- Помогать с оформлением командировок
- Предоставлять информацию о зарплате
- Отвечать на вопросы по кадровым темам

ПРАВИЛА:
1. Будь вежлив и профессионален
2. Всегда используй инструменты для получения данных
3. Не придумывай информацию
4. Уточняй, о каком сотруднике идёт речь
5. Храни конфиденциальность — показывай данные только самому сотруднику

ОГРАНИЧЕНИЯ:
- НЕ разглашай данные других сотрудников
- НЕ изменяй данные без подтверждения
- НЕ отвечай на вопросы не по теме

ФОРМАТ ОТВЕТОВ:
- Кратко и по существу
- Используй списки для перечислений
- Указывай источник данных
```

## Инструменты

### 1. Получить остаток отпуска

```
Наименование: Получить остаток отпуска
Описание: Возвращает количество дней отпуска для сотрудника.
          Используй, когда спрашивают об отпуске.

Параметры:
- employee (string): ФИО или табельный номер

Код:
ФИОСотрудника = Параметры.employee;

Запрос = Новый Запрос;
Запрос.Текст = 
"ВЫБРАТЬ
|    ОстаткиОтпусков.ОстатокДней КАК Дней,
|    ОстаткиОтпусков.Использовано КАК Использовано,
|    ОстаткиОтпусков.Всего КАК Всего
|ИЗ
|    РегистрСведений.ОстаткиОтпусков КАК ОстаткиОтпусков
|ГДЕ
|    ОстаткиОтпусков.Сотрудник.Наименование ПОДОБНО &ФИО";
Запрос.УстановитьПараметр("ФИО", "%" + ФИОСотрудника + "%");

Выборка = Запрос.Выполнить().Выбрать();
Если Выборка.Следующий() Тогда
    Результат = Новый Структура(
        "ОстатокДней, Использовано, Всего",
        Выборка.Дней, Выборка.Использовано, Выборка.Всего
    );
Иначе
    Результат = Новый Структура("Ошибка", "Сотрудник не найден");
КонецЕсли;
```

### 2. Создать заявку на отпуск

```
Наименование: Создать заявку на отпуск
Описание: Создаёт заявку на отпуск. Используй после подтверждения.

Параметры:
- employee (string): ФИО сотрудника
- date_from (string): Дата начала (YYYY-MM-DD)
- date_to (string): Дата окончания (YYYY-MM-DD)

Код:
Сотрудник = НайтиСотрудника(Параметры.employee);
ДатаС = Дата(Параметры.date_from);
ДатаПо = Дата(Параметры.date_to);

Заявка = Документы.ЗаявкаНаОтпуск.СоздатьДокумент();
Заявка.Дата = ТекущаяДата();
Заявка.Сотрудник = Сотрудник;
Заявка.ДатаНачала = ДатаС;
Заявка.ДатаОкончания = ДатаПо;
Заявка.Записать();

Результат = Новый Структура(
    "Успех, НомерЗаявки",
    Истина, Заявка.Номер
);
```

### 3. Получить информацию о зарплате

```
Наименование: Получить информацию о зарплате
Описание: Возвращает информацию о начислениях за период.

Параметры:
- employee (string): ФИО сотрудника
- period (string): Период (YYYY-MM)

Код:
Сотрудник = Параметры.employee;
Период = Дата(Параметры.period + "-01");

Запрос = Новый Запрос;
Запрос.Текст = 
"ВЫБРАТЬ
|    Начисления.ВидНачисления.Наименование КАК Вид,
|    Начисления.Сумма КАК Сумма
|ИЗ
|    РегистрНакопления.НачисленияСотрудникам КАК Начисления
|ГДЕ
|    Начисления.Сотрудник.Наименование ПОДОБНО &ФИО
|    И Начисления.Период = &Период";
Запрос.УстановитьПараметр("ФИО", "%" + Сотрудник + "%");
Запрос.УстановитьПараметр("Период", Период);

Таблица = Запрос.Выполнить().Выгрузить();
// Формирование результата...
```

## Примеры диалогов

### Запрос остатка отпуска

```
Пользователь: Сколько у меня дней отпуска?

Агент: Уточните, пожалуйста, вашу фамилию или табельный номер.

Пользователь: Иванов Иван

Агент: 📊 Проверяю информацию...

У вас, Иванов Иван, осталось:
- Остаток дней отпуска: **14 дней**
- Использовано в этом году: 10 дней
- Всего положено: 28 дней

Хотите оформить заявку на отпуск?
```

### Оформление заявки

```
Пользователь: Да, хочу в отпуск с 1 по 14 февраля

Агент: Подтвердите данные заявки:
- Сотрудник: Иванов Иван
- Дата начала: 01.02.2026
- Дата окончания: 14.02.2026
- Количество дней: 14

Создать заявку? (да/нет)

Пользователь: Да

Агент: ✅ Заявка на отпуск создана!
Номер заявки: ЗО-000123

Заявка направлена на согласование руководителю.
```
