## Как использовать примеры

### Вариант 1: Создать вручную

1. Откройте страницу примера
2. Создайте агента с указанными параметрами
3. Создайте инструменты
4. Адаптируйте под свои нужды

### Вариант 2: Импорт

1. Получите JSON файл примера
2. Используйте обработку "Экспорт/импорт агентов"
3. Импортируйте агента
4. Настройте модель и параметры

## Адаптация примеров

### Шаг 1: Изучите пример

- Понять назначение
- Изучить промпт
- Разобрать инструменты

### Шаг 2: Адаптируйте

- Измените названия полей под вашу конфигурацию
- Адаптируйте запросы
- Настройте права доступа

### Шаг 3: Протестируйте

- Проверьте все сценарии
- Соберите обратную связь
- Улучшите

## Структура примера

Каждый пример содержит:

1. **Описание задач** — что делает агент
2. **Конфигурация** — настройки агента
3. **Инструменты** — код и параметры
4. **Промпты** — системный промпт
5. **Примеры диалогов** — как выглядит общение
