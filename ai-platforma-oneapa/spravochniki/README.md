## Ключевые справочники

### Агенты

**Центральный справочник системы.** Определяет:
- Какую модель использует агент
- Какой системный промпт применять
- Какие инструменты доступны
- Кто может использовать агента
- При каком событии агент активируется

### Инструменты

**Функциональные возможности агентов.** Определяет:
- Что агент может делать
- Какие параметры принимает инструмент
- Какой код выполняется
- Кто может использовать инструмент

### Модели

**Подключение к LLM.** Определяет:
- Какой провайдер используется
- Параметры подключения (ключи, URL)
- Какая конкретная модель

## Общие принципы работы

### Создание элемента

1. Откройте справочник
2. Нажмите "Создать"
3. Заполните обязательные поля
4. Сохраните

### Иерархические справочники

Справочники Агенты, Инструменты и MCP серверы поддерживают иерархию (группы):

```
📁 Агенты
├── 📁 Финансовые
│   ├── Бухгалтер
│   └── Финансовый аналитик
├── 📁 HR
│   ├── Кадровик
│   └── Рекрутер
└── 📁 Поддержка
    ├── Первая линия
    └── Техническая поддержка
```

{% endhint %}
