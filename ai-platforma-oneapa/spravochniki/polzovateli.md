# Справочник "Пользователи"

Справочник `APA_Пользователи` предназначен для учёта пользователей системы OneAPA.

## Назначение

Справочник используется для:
- Идентификации пользователей в системе
- Разграничения доступа к агентам
- Разграничения доступа к инструментам
- Авторизации через OAuth

## Характеристики справочника

| Параметр | Значение |
|----------|----------|
| Имя | APA_Пользователи |
| Иерархический | Нет |
| Владельцы | Нет |

## Реквизиты

| Реквизит | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| **Код** | Строка(9) | Да | Уникальный код |
| **Наименование** | Строка(150) | Да | Имя пользователя |
| **Логин** | Строка | Нет | Логин для входа |
| **Пароль** | Строка | Нет | Пароль (хранится в зашифрованном виде) |
| **ИдентификаторOAuth** | Строка | Нет | ID для OAuth авторизации |

## Создание пользователя

### Шаг 1: Открытие справочника

1. Откройте справочник "Пользователи" (APA_Пользователи)
2. Нажмите "Создать"

### Шаг 2: Заполнение данных

| Поле | Пример |
|------|--------|
| Наименование | Иванов Иван Иванович |
| Логин | ivanov |
| Пароль | ******** |

### Шаг 3: Сохранение

Нажмите "Записать и закрыть"

## Использование

### В агентах

Для ограничения доступа к агенту:

1. Откройте агента
2. Перейдите на вкладку "Пользователи"
3. Добавьте пользователей из справочника

### В инструментах

Для ограничения доступа к инструменту:

1. Откройте инструмент
2. Перейдите на вкладку "Доступность"
3. Добавьте пользователей

## Связь с пользователями 1С

{% hint style="info" %}
Справочник APA_Пользователи независим от справочника пользователей платформы 1С. При необходимости создайте механизм синхронизации.
{% endhint %}


## OAuth авторизация

### Назначение

Поле `ИдентификаторOAuth` используется для авторизации через внешние системы (например, при работе через Web UI).

### Настройка

1. Получите OAuth ID пользователя из внешней системы
2. Укажите его в поле "Идентификатор OAuth"

## Рекомендации

### Именование

Используйте понятные имена:
- ✅ "Иванов Иван Иванович"
- ✅ "Главный бухгалтер"
- ❌ "user1"
- ❌ "test"

### Безопасность

- Используйте сложные пароли
- Регулярно меняйте пароли
- Удаляйте неактивных пользователей

### Группировка

Для удобства создайте несколько пользователей по ролям:
- HR_Специалист
- Бухгалтер
- Менеджер_продаж
- Администратор

## Устранение проблем

### Пользователь не видит агента

1. Проверьте, добавлен ли пользователь в табличную часть "Пользователи" агента
2. Если список пуст — агент доступен всем

### Пользователь не может использовать инструмент

1. Проверьте табличную часть "Доступность" инструмента
2. Добавьте пользователя или очистите список
