# Установка

Этот раздел описывает быструю установку OneAPA. Для более детальных инструкций см. раздел [Установка и развёртывание](../ustanovka-i-razvertyvanie/).

## Шаг 1: Установка конфигурации 1С

### 1.1 Получение файла конфигурации

Получите файл конфигурации OneAPA (`.cf` или `.cfe`) от поставщика.

### 1.2 Загрузка в базу данных

**Вариант А: Новая база данных**

1. Создайте новую информационную базу
2. Откройте базу в Конфигураторе
3. Меню "Конфигурация" → "Загрузить конфигурацию из файла"
4. Выберите файл конфигурации OneAPA
5. Обновите конфигурацию базы данных (F7)

**Вариант Б: Объединение с существующей конфигурацией**

1. Откройте вашу базу в Конфигураторе
2. Меню "Конфигурация" → "Сравнить, объединить с конфигурацией из файла"
3. Выберите файл конфигурации OneAPA
4. Выберите объекты для объединения (все объекты с префиксом `APA_`)
5. Выполните объединение
6. Обновите конфигурацию базы данных (F7)

### 1.3 Проверка установки

1. Откройте базу в режиме "1С:Предприятие"
2. Проверьте наличие команды "Чат" в панели навигации
3. Проверьте наличие справочников:
   - Агенты
   - Инструменты
   - Модели

## Шаг 2: Установка Proxy-сервера

Выберите один из вариантов установки.

### Вариант А: Docker (рекомендуется)

{% hint style="success" %}
Docker — самый простой способ запустить Proxy-сервер.
{% endhint %}

#### 2A.1 Установка Docker

**Windows:**
1. Скачайте [Docker Desktop](https://www.docker.com/products/docker-desktop/)
2. Установите и перезагрузите компьютер
3. Запустите Docker Desktop

**Linux:**
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install docker.io docker-compose

# CentOS/RHEL
sudo yum install docker docker-compose
sudo systemctl start docker
sudo systemctl enable docker
```

#### 2A.2 Получение образа

Получите файлы Proxy-сервера и перейдите в каталог:

```bash
cd /path/to/OneAPAProxy
```

#### 2A.3 Сборка и запуск

```bash
# Сборка образа
docker build -t oneapa-proxy .

# Запуск контейнера
docker run -d \
  --name oneapa-proxy \
  -p 9000:9000 \
  -e LICENSE_KEY=your_license_key \
  oneapa-proxy
```

#### 2A.4 Проверка

```bash
# Проверка статуса
docker ps

# Проверка логов
docker logs oneapa-proxy

# Проверка работоспособности
curl http://localhost:9000/health
```

### Вариант Б: Python

#### 2B.1 Клонирование/копирование файлов

Скопируйте файлы Proxy-сервера в выбранный каталог:

```bash
cd /path/to/OneAPAProxy
```

#### 2B.2 Создание виртуального окружения

```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/Mac)
source venv/bin/activate
```

#### 2B.3 Установка зависимостей

```bash
pip install -r requirements.txt
```

#### 2B.4 Настройка переменных окружения

Создайте файл `.env` или установите переменные окружения:

```bash
# Windows (PowerShell)
$env:LICENSE_KEY = "your_license_key"

# Linux/Mac
export LICENSE_KEY="your_license_key"
```

#### 2B.5 Запуск сервера

```bash
python main.py
```

#### 2B.6 Проверка

```bash
curl http://localhost:9000/health
```

Ожидаемый ответ:

```json
{
  "message": "OK",
  "version": "1.0.1",
  "build_date": "2025-12-03"
}
```

## Шаг 3: Настройка связи 1С и Proxy

### 3.1 Открытие настроек

В 1С откройте настройки OneAPA:
- Меню "Панель действий" → "Настройки"
- Или команда `APA_Настройки`

### 3.2 Указание URL Proxy-сервера

Заполните поле "URL Proxy сервера":

```
http://localhost:9000
```

Или, если Proxy на другом сервере:

```
http://proxy-server.local:9000
```

### 3.3 Проверка подключения

Нажмите кнопку "Проверить подключение". Должно появиться сообщение об успешном подключении.

## Шаг 4: Настройка LLM провайдера

### 4.1 Создание модели

1. Откройте справочник "Модели" (APA_Модели)
2. Создайте новый элемент
3. Заполните поля:

**Для OpenAI:**

| Поле | Значение |
|------|----------|
| Наименование | OpenAI GPT-4o |
| Провайдер | OpenAI |
| Ключ | sk-... (ваш API ключ) |
| Каталог | gpt-4o |
| URL | (оставьте пустым) |

**Для Yandex GPT:**

| Поле | Значение |
|------|----------|
| Наименование | Yandex GPT |
| Провайдер | Yandex |
| Ключ | (IAM токен) |
| Каталог | (folder_id) |
| URL | (оставьте пустым) |

**Для Ollama:**

| Поле | Значение |
|------|----------|
| Наименование | Ollama Llama3 |
| Провайдер | LocalOllama |
| Ключ | (оставьте пустым) |
| Каталог | llama3 |
| URL | http://localhost:11434 |

### 4.2 Проверка модели

Сохраните модель. При сохранении система не проверяет подключение — проверка будет выполнена при первом использовании.

## Итоговая схема

После выполнения всех шагов ваша система должна выглядеть так:

```
┌─────────────────────────────────────────────────────────────────┐
│                        Ваш сервер                                │
│                                                                  │
│  ┌─────────────────┐              ┌─────────────────────────┐   │
│  │ 1С:Предприятие  │              │    Proxy Server         │   │
│  │  + OneAPA       │◄────────────►│    (Docker/Python)      │   │
│  │                 │   :9000      │                         │   │
│  │  • Агенты       │              │    • FastAPI            │   │
│  │  • Модели       │              │    • LangGraph          │   │
│  │  • Инструменты  │              │    • Chainlit UI        │   │
│  └─────────────────┘              └───────────┬─────────────┘   │
│                                               │                  │
└───────────────────────────────────────────────┼──────────────────┘
                                                │ :443
                                                ▼
                                        ┌─────────────────┐
                                        │   LLM Provider  │
                                        │   (OpenAI и др.)│
                                        └─────────────────┘
```

## Устранение проблем

| Проблема | Решение |
|----------|---------|
| Docker не запускается | Убедитесь, что Docker Desktop запущен |
| Порт 9000 занят | Измените порт: `-p 9001:9000` |
| Ошибка подключения 1С к Proxy | Проверьте firewall и URL |
| Proxy не видит LLM | Проверьте API ключ и доступ к интернету |
