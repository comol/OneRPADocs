# Быстрый старт

{% hint style="success" %}
Этот раздел поможет вам запустить OneAPA и создать первого ИИ агента примерно за 15-20 минут.
{% endhint %}

## Цель раздела

После выполнения инструкций этого раздела вы:

- Установите и настроите OneAPA
- Создадите своего первого ИИ агента
- Протестируете его в чате

## Что вам понадобится

| Компонент | Требование |
|-----------|------------|
| 1С:Предприятие | Версия 8.3.20 или выше |
| Python | Версия 3.11 или выше (или Docker) |
| LLM провайдер | API ключ (OpenAI, Yandex и др.) или Ollama |
| Сеть | Доступ к LLM провайдеру (или локальная сеть для Ollama) |

## Рекомендуемый путь для начинающих

Если вы впервые работаете с OneAPA, рекомендуем:

1. **Начните с OpenAI** — самый простой вариант, требует только API ключ
2. **Используйте Docker** — упрощает запуск Proxy сервера
3. **Создайте простого агента** — без инструментов, только для проверки связи

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| Нет подключения к Proxy | Проверьте URL и порт в настройках |
| Ошибка авторизации LLM | Проверьте API ключ |
| Агент не отвечает | Проверьте логи Proxy сервера |
| Таймаут | Увеличьте значение таймаута |
