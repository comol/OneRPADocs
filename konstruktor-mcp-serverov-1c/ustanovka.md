# Установка

Подробная инструкция по установке Конструктора MCP серверов для 1С.

## Состав дистрибутива

После приобретения вы получаете архив со следующими файлами:

| Файл | Назначение |
|------|------------|
| `OneMCP.cfe` | Расширение конфигурации 1С |
| `ИнструментыДляРазработки.xml` | Готовые инструменты для вайб-кодинга |
| `default.vrd` | Пример файла публикации HTTP-сервиса |
| `mcpconfig.json` | Пример конфигурации MCP-клиента |
| `httpd.conf` | Пример настройки Apache для нескольких публикаций |
| `Readme.txt` | Описание файлов |

## Установка расширения

### Способ 1. Через Конфигуратор

1. Запустите 1С:Предприятие в режиме **Конфигуратор**
2. Откройте меню **Конфигурация → Расширения конфигурации**
3. В открывшемся окне нажмите кнопку **Добавить из файла**
4. Выберите файл `OneMCP.cfe`
5. Подтвердите добавление расширения
6. Выполните **Конфигурация → Обновить конфигурацию базы данных** (F7)

### Способ 2. Через командную строку

```cmd
"C:\Program Files\1cv8\8.3.XX.XXXX\bin\1cv8.exe" DESIGNER /F "C:\bases\YourBase" /LoadCfg "OneMCP.cfe" /UpdateDBCfg
```

{% hint style="info" %}
Замените путь к платформе и базе на актуальные для вашей системы.
{% endhint %}

## Проверка установки

После установки расширения в конфигурации появятся:

### Справочники

- **APA_Инструменты** — хранение инструментов MCP

### HTTP-сервисы

- **APA_MCP** — HTTP-сервис для протокола MCP

## Загрузка инструментов для разработки

Файл `ИнструментыДляРазработки.xml` содержит готовые инструменты для вайб-кодинга.

### Загрузка через интерфейс

1. Запустите базу в режиме **1С:Предприятие**
2. Откройте справочник **APA_Инструменты**
3. Используйте функцию загрузки данных из XML
4. Выберите файл `ИнструментыДляРазработки.xml`

### Загрузка через обработку

Если в конфигурации есть стандартная обработка загрузки XML:

1. Откройте обработку загрузки данных
2. Укажите путь к файлу `ИнструментыДляРазработки.xml`
3. Выполните загрузку

## Требования к окружению

### Платформа 1С

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| Версия платформы | 8.3.20 | 8.3.24+ |
| Режим совместимости | Управляемые формы | — |
| Лицензия | Серверная или файловая | Серверная |

### Веб-сервер

Для публикации HTTP-сервиса MCP требуется веб-сервер:

| Веб-сервер | Версия | Примечания |
|------------|--------|------------|
| Apache | 2.4+ | Рекомендуется, поддержка в Linux и Windows |
| IIS | 10+ | Только Windows |

### Сетевые требования

- HTTP-сервис должен быть доступен с машины, где работает MCP-клиент
- По умолчанию используется порт 80 (HTTP) или 443 (HTTPS)
- Firewall должен разрешать входящие подключения на порт публикации

## Возможные проблемы

### Расширение не загружается

**Причина**: Несовместимость версий платформы или конфигурации.

**Решение**: 
- Убедитесь, что версия платформы 8.3.20 или выше
- Проверьте режим совместимости конфигурации
- Проверьте журнал регистрации на наличие ошибок

### HTTP-сервис недоступен

**Причина**: Неправильная публикация или настройка веб-сервера.

**Решение**:
- Проверьте статус веб-сервера (Apache/IIS)
- Убедитесь, что публикация корректно настроена
- Проверьте логи веб-сервера на наличие ошибок

### Инструменты не загружаются

**Причина**: Некорректный формат XML или отсутствие прав.

**Решение**:
- Проверьте, что у пользователя есть права на запись в справочник
- Убедитесь, что XML-файл не повреждён
- Попробуйте загрузить в режиме эксклюзивного доступа
