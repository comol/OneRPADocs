# Linux и macOS

Основная платформа обеих поставок — Windows x64. Для Linux и macOS выпускаются отдельные архивы той же версии бандла. Набор интерфейсов на них уже, а часть действий 1С пока доступна только в Windows.

| Поставка | Windows x64 | Linux x64 | macOS, Apple Silicon (ARM64) |
|---|---|---|---|
| Pi 1C | `Pi-1C.exe`: терминал, Warp, Pi Web | `./Pi-1C`: терминал | `./Pi-1C`: терминал |
| DSH 1С | DSH Desktop: `DSH-Desktop-1C.exe` | DSH Web: `./DSH-1C`, браузер на `127.0.0.1` | DSH Desktop: `./DSH-Desktop-1C` |

Архивов для Mac на процессоре Intel нет.

## Установка

Распакуйте весь ZIP в отдельный каталог с правом записи и запускайте лаунчер из терминала в этом каталоге. Node.js, Python, Java, BSL Language Server, `rg` и `fd` уже лежат в архиве. Ключей, профилей и истории в архиве нет: они появляются при первом запуске.

Linux-архив собран для x86_64 с glibc. Проверялся на Debian 12 (glibc 2.36). Alpine и другие дистрибутивы на musl не поддерживаются.

## Pi в Linux и macOS

```bash
./Pi-1C --working-directory ~/projects/my-config
./Pi-1C --projects
./Pi-1C --new-project ~/projects/new-config
./Pi-1C --setup
./Pi-1C --check-updates
./Pi-1C --help
```

| Параметр | Что делает |
|---|---|
| `--working-directory <папка>` | Открыть проект в терминале |
| `--projects` | Выбрать проект из списка последних |
| `--add-project <папка>`, `--new-project <папка>` | Добавить существующую папку или создать новую |
| `--setup` | Настроить `.dev.env` проекта без запуска модели |
| `--state-directory <папка>` | Другой каталог состояния |
| `--check-updates` | Проверить обновление для своей ОС и архитектуры |
| `--headless`, `--acp` | Без TUI: однократный запуск или RPC |

Окна выбора проектов, Warp и Pi Web здесь нет: работа идёт в обычном терминале. Внутри сессии доступны те же команды, что в Windows: `/setup`, `/settings1c`, `/login`, `/app-update` и остальные.

Каталог состояния:

- Linux — `~/.local/state/pi1c` или `$XDG_STATE_HOME/pi1c`;
- macOS — `~/Library/Application Support/Pi1C/state`.

Переопределить его можно переменной `PI1C_STATE_DIR` или параметром `--state-directory`. Каталог не может лежать внутри поставки.

## DSH в Linux: Web

```bash
./DSH-1C --project ~/projects/my-config
```

Лаунчер поднимает DSH на `127.0.0.1` на свободном порту и открывает браузер. Адрес содержит служебный токен: не пересылайте его. Чтобы задать порт, добавьте `--port <номер>`, чтобы не открывать браузер — `--no-open`. Остановка — Ctrl+C в терминале.

Это та же сборка, что и DSH Desktop для Windows, только в браузерном профиле: пресеты, MCP, OpenSpec, метаданные, модели и подписки работают так же. Трея и отдельного окна нет: закрытие вкладки браузера не останавливает сервер, останавливает Ctrl+C.

## DSH на macOS: Desktop

```bash
./DSH-Desktop-1C --project ~/projects/my-config
```

Запускается официальное приложение DeepSeek Harness Desktop с изменениями бандла. Приложение подписано ad-hoc, нотаризации Apple нет. При первом запуске macOS может предупредить о неизвестном разработчике. Разрешите запуск в «Системные настройки → Конфиденциальность и безопасность», если доверяете скачанному архиву.

{% hint style="warning" %}
Архивы для macOS проверены статически: состав, архитектура, подпись. Запуск на настоящем Mac перед выпуском не проверялся. Если приложение не стартует, пришлите вывод терминала в поддержку.
{% endhint %}

## Что работает только в Windows

| Возможность | Что делать в Linux и macOS |
|---|---|
| Скрипты навыков 1С (Windows PowerShell): выгрузка, загрузка, операции Конфигуратора | Использовать MCP-серверы или CLI платформы 1С. Агент объяснит, что скрипт недоступен |
| Вызов 1С через COM | Недоступен |
| Часть операций метаданных и заимствование объекта в расширение помощником DSH | Недоступны: агент сообщает об этом и не меняет файлы |
| Установщики правил и дополнительных инструментов на PowerShell | Недоступны. Уже установленные правила работают |
| Отдельный ZIP-экспорт и импорт настроек DSH | Недоступен. Обновление поставки сохраняет настройки |
| Telegram в DSH: токен бота хранится средствами Windows | Недоступен |
| Warp и Pi Web | Только Windows. В Linux и macOS Pi работает в терминале |

Доступ к DSH с телефона проверялся в DSH Desktop для Windows.

Чтение и поиск по выгрузке, правка BSL, OpenSpec, слой знаний, MCP и локальная проверка BSL Language Server работают на всех трёх платформах.

## Обновление

Встроенное обновление выбирает архив того же продукта, варианта, ОС и архитектуры. Linux-установка не получит Windows-архив, и наоборот. Перед ручной заменой закройте приложение и храните папку поставки целиком.
