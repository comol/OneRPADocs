# Требования

## Общие

- **Windows 10 или 11, x64** — основная платформа.
- Или **Linux x64** с glibc (проверено на Debian 12), или **macOS на Apple Silicon**. Возможностей там меньше, см. [Linux и macOS](platformy.md). Alpine/musl и Mac на Intel не поддерживаются.
- Свободное место: для Pi не меньше 6 ГБ на распаковку. Обновление из приложения временно держит рядом с поставкой скачанный архив и резервную копию, место нужно и на это.
- Отдельная папка проекта 1С вне каталога поставки: выгрузка в файлы, EDT или пустой каркас, который создаст мастер.
- Запущенные MCP-серверы 1С из дистрибутива `MCP_Distr`. Образы в ZIP бандла не входят. Установка серверов — в разделе [MCP серверы для 1С](../mcp-servery-1c/README.md), состав для бандлов — на странице [MCP в Pi и DSH](mcp.md).
- Доступ к модели: подписка или ключ провайдера. Пароли и ключи вводятся в мастере или в настройках, не в чате. Список провайдеров — [Модели, подписки и аккаунты](modeli-i-podpiski.md).
- Для исполнения в 1С — настроенная информационная база. Удобнее тестовая копия, а не рабочая база.

Профильные серверы слушают порты **8000, 8002, 8003, 8004, 8006, 8007, 8008 и 8030**. Порт 8030 — UI-тесты, в обоих бандлах. Стандартная инструкция MCP публикует QA на 8020, как совместить — в [MCP в Pi и DSH](mcp.md#серверы-поставки). Готовность Pi считает семь серверов без QA. Готовность DSH считает Graph и, пока у него нет поиска кода, ещё и Code. Молчащие серверы не мешают открыть чат.

## Pi

- Node.js в клиентском ZIP уже есть (`runtime/node`). Для рабочего дерева без этого runtime нужен Node.js 22.19 или новее.
- Первый запуск установщика: `Pi-1C.exe --install`. Если MCP ещё не подняты, добавьте `-SkipMcpProbe`.
- Зависимости внутри полного ZIP сверяются по манифесту. Несовпадение блокирует установку. Восстановление из lock-файла — только с `-ForceRestore`.
- BSL Language Server и portable Java уже в поставке. Из сети на старте ничего не скачивается. Исключение — официальные CLI Google Antigravity и Meta Muse: они скачиваются при первом подключении этих подписок.

## DSH Desktop

- Node.js и Electron ставить не нужно: они входят в ZIP (`runtime/node`, `runtime/desktop`).
- Права администратора не нужны. Поставка в системе не регистрируется и не создаёт глобальную команду `dsh`.
- ZIP распаковывайте целиком в отдельную папку с правом записи, не поверх другой версии и не запуская EXE прямо из архива.
- `install.ps1` необязателен: он только готовит профиль, не открывая окно.
- Исполнители Claude Code и Codex для ACP в архив не входят. При первом включении DSH скачивает их с `registry.npmjs.org`, около 130–170 МБ: нужны интернет и доступ к этому адресу через прокси. Модели персонажа Moon Rabbit подключаются из архива автора. Остальное работает без загрузок.

## Что не требуется

Отдельная установка классического Pi или классического DeepSeek Harness не нужна: в ZIP уже собранное ядро и контур 1С. Пакеты из сети на первом запуске не ставятся. Исключения скачиваются только при первом включении своей функции: официальные CLI Google и Muse, а в DSH ещё исполнители Claude Code и Codex.
