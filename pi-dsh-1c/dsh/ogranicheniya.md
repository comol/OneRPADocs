# Ограничения DSH Desktop

Это рабочая beta. Окно Desktop — основной интерфейс. Отдельной Web-поставки для Windows больше нет. В Linux DSH работает как Web, на macOS — как Desktop, с ограничениями: см. [Linux и macOS](../platformy.md).

- Отдельной защиты информационной базы нет. Метка `test` или `production` ничего не запрещает. Загрузка исходников — `onec_deploy` после вашего подтверждения. Вызов через COM — `onec_com_execute`, и только если backend равен `com`.
- Недоступный необязательный MCP, неподтверждённый backend и расхождение хеша не закрывают чат. Код 1 у `--doctor` означает поломку профиля поставки. Смысловая правка метаданных через MCP при этом ждёт обязательный сервер и свежий индекс.
- Дерево метаданных по умолчанию читает локальную выгрузку, не живой граф. Ленивые детали объекта ограничены 5000 узлами.
- После смены адресов MCP, режима MCP-first, сжатия контекста или включения локального расширения нужен перезапуск. Сервер, появившийся после старта, в текущей сессии сам не подключится.
- Закрытие окна не завершает процесс: приложение остаётся в трее.
- В очень большом Git-репозитории, например с выгрузкой ERP, снимок рабочей папки не укладывается в 5 секунд. Первый ход ждёт эти 5 секунд, дальше до перезапуска DSH такие снимки для этого репозитория не делаются, и ходы не задерживаются. В списке изменений хода остаются правки файловыми инструментами, изменения, сделанные командами оболочки, в него не попадают.
- Автоматических снимков файлов нет. `/rewind` не восстанавливает базу и не восстанавливает правку, если точки до неё не было.
- Локальное расширение — код с правами процесса. Текстовый скан не является песочницей.
- ASK и PLAN отличают пишущие инструменты по имени, не по песочнице.
- Русский интерфейс — слой совместимости. Новые строки ядра могут остаться английскими. Технические предупреждения MCP тоже бывают английскими.
- Java и BSL Language Server входят в архив каждой платформы.
- Платный Anthropic API не используется. Подписки описаны в окне моделей. Наличие CLI не означает вход. Проверки поставки не подтверждают за вас каждый внешний аккаунт и тариф.
- Ротация аккаунтов и резервные модели срабатывают только до начала ответа. Начатый ответ и вызовы инструментов не повторяются. Google Gemini работает только в BUILD.
- Защита персональных данных по умолчанию выключена и основана на правилах, а не на юридическом обезличивании. При включённой защите Claude через Claude Code, внешние делегаты и вложения блокируются: см. [Защита персональных данных](../zashchita-pdn.md).
- Команды агентов — beta, полный сценарий принят только для пресета 1С Full. Расписание срабатывает, только пока DSH запущен.
- Ассистент, персонаж и голосовое поручение выключены, пока их не включить на странице ассистента. Распознавание речи использует ключ OpenAI API и оплачивается отдельно от подписки. Глобальное сочетание вне активного окна есть в Windows Desktop.
- Отдельного плагина зрения нет. Прикреплённое изображение смотрит выбранная модель, если у неё есть своё зрение.
- Agent Desktop в поставке выключен, пока его не включат в настройках инструментов. По умолчанию DSH читает свои правила и не подмешивает `CLAUDE.md`, `.claude` и `.cursor`.
- Доступ с телефона работает в локальной сети или через VPN, публичный туннель не создаётся. Сертификат самоподписанный.
- Команды `/journal1c`, `/merge1c`, `/meta-apply` и `/install-*` передают процедуру. Они не равны уже выполненной операции.
- Часть дублирующих пакетов в стандартный ZIP не входит. История ввода включена. Пакеты Pi подключаются выбором, а не все сразу.
- Телеметрия сессий в DeepSeek по умолчанию выключена (`DSH_TELEMETRY_MODE=DISABLED`).
- `.agentignore` в корне проекта, если вы его завели, ограничивает и поиск, и shell, и MCP, и делегирование: непрозрачный инструмент нельзя надёжно отфильтровать по выходу. Это ограничение beta. Снятие паттернов возвращает обычный доступ.
- Синтаксическая проверка не заменяет тест в 1С. Откат файлов не откатывает базу.

Фактический состав чата смотрите в интерфейсе: он может отличаться от пресета, выбранного для новых чатов. Диагностика поставки — `DSH-Desktop-1C.exe --doctor`.
