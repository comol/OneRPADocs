# Защита персональных данных

В обе поставки входит локальный плагин «Защита персональных данных (Россия)». Перед отправкой модели он заменяет найденные ФИО, телефоны, адреса, ИНН, СНИЛС, паспортные и платёжные реквизиты обозначениями вида `[PERSON_1]`, `[PHONE_1]`, `[INN_1]`. Распознавание идёт на вашем компьютере, без облака, без Python и без отдельной модели.

**По умолчанию защита выключена** в Pi и в DSH. Включаете её вы.

## Как включить

| | Pi 1C | DSH 1С |
|---|---|---|
| Включить | `/pii on` — текущая сессия и новые сессии этого запуска | «Плагины → Установленные плагины» → «Защита персональных данных (Россия)», затем перезапуск. Дальше маскирование действует во всех чатах, пока вы не выключите его командой |
| Выключить | `/pii off` | `/pii off` — текущий чат и его субагенты |
| Состояние | `/pii status` — счётчики по типам, без самих значений | `/pii status` — число находок в последней отправке |
| Постоянно | `/pii default on\|off` | `/pii project on\|off` — для чатов проекта до перезапуска DSH |

## Что фильтруется

Весь окончательный запрос к модели: ваши сообщения, системные инструкции, результаты и аргументы инструментов, старая история, сжатие контекста и названия чатов. Встроенные субагенты работают с той же защитой.

Таблица соответствий живёт только в памяти процесса. Модели она не передаётся и на диск не пишется. Если фильтр сломался, запрос не отправляется: исходный текст как запасной вариант не уходит.

## Ограничения

- Распознавание по правилам. Нестандартная запись может проскочить, обычный текст — замаскироваться по ошибке. Это снижение риска, а не юридическое обезличивание.
- OCR нет. Пока защита включена, изображения и вложения не отправляются.
- Claude через Claude Code, внешние CLI-субагенты и делегаты при включённой защите блокируются: их обращения к модели идут мимо фильтра. В Pi то же касается Cursor SDK. Для них выберите другого провайдера или осознанно выполните `/pii off`.
- Оригиналы в ответе автоматически не восстанавливаются. Точный поиск или правка по псевдониму может потребовать вашего участия.
- Файлы проекта и локальные журналы могут содержать персональные данные: плагин защищает только то, что уходит в модель. Произвольные сетевые команды и внутренний трафик сторонних MCP-серверов за его границей.

После включения плагина в DSH или обновления поставки полностью перезапустите приложение, включая выход из трея.
