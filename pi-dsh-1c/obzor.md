# Что это

Обычный Pi и обычный DeepSeek Harness умеют диалог, модель и правку файлов. Они не знают, как устроена конфигурация 1С, где справка платформы и чем выгрузка отличается от информационной базы.

VibeCoding1C оставляет ядро и собирает вокруг него маршрут разработки 1С.

## Что общего

- Поиск объектов, процедур, форм и связей начинается с [MCP-серверов 1С](mcp.md), а не с чтения всего дерева выгрузки.
- Нетривиальное изменение сначала описывается в [OpenSpec](openspec-i-znaniya.md): цель, сценарии, задачи, затем код.
- Факты и правила конкретной конфигурации лежат в проекте, в `.ai-rules/knowledge/`, и попадают в работу только после вашего подтверждения.
- Доступ агента задаётся отдельно: спросить, спланировать или менять файлы. См. [Режимы](rezhimy.md).
- Метаданные не правятся руками как сырой XML. Их меняют профильные навыки и проверенные скрипты.
- Локальная проверка BSL Language Server входит в поставку и не требует MCP. Java для неё тоже входит в комплект Windows x64.
- Синтаксическая проверка не заменяет загрузку в тестовую базу.
- Отдельной «защиты базы только на чтение» нет. Операции с информационной базой идут с обычным подтверждением инструмента и в рамках выбранного доступа. Для проб берите тестовую копию.
- Агент может дописать себе локальный навык или плагин: запись, проверка, включение и откат остаются под вашим контролем.

## Чем поставки отличаются

**Pi 1C** — изолированная сборка Pi Coding Agent. Версия бандла **1.1.0**, ядро `@earendil-works/pi-coding-agent` **1.4.0**. Интерфейс — терминал (TUI), вкладка комплектного Warp или браузерный клиент `-Web`. Произвольные `bash` и `powershell` модели закрыты: профильные действия 1С идут через один из хешированных скриптов навыков. Встроенного отката файлов нет: файлы возвращают через Git проекта.

**DSH Desktop 1С** — единственная активная поставка DeepSeek Harness для 1С, на официальном Desktop **0.2.1-rc.3**. Отдельная Web-поставка снята; браузерный режим внутри Desktop остаётся запасным. В окне рядом чат, дерево метаданных, редактор BSL, панель OpenSpec, карточки MCP и терминал PowerShell. Откат файлов — ручные точки `/checkpoint` и `/rewind`. Автоматические снимки перед правкой выключены.

Имена части команд совпадают, а смысл нет. Перед переносом привычки смотрите [таблицу соответствия](sootvetstvie-komand.md).

## Кому подходит

Разработчику, который дорабатывает конфигурации и расширения 1С, разбирает чужой код и хочет вести изменение от требования до проверяемого результата. Каталог выгрузки и работающая база — разные состояния: правка файлов сама по себе базу не обновляет.

## Чего не обещает beta

- Бандл не устанавливает и не запускает Docker-контейнеры MCP, Cognee, OpenViking, EDT-MCP и Windows-MCP. Он проверяет их и объясняет, как подключить.
- Без обязательных MCP сессия жива. В Pi это режим degraded: нет инструментов молчащего обязательного сервера. В DSH молчание необязательного сервера — предупреждение, а правка метаданных через MCP ждёт Graph и свежий индекс. Задачу нельзя считать проверенной.
- Откат файлов не восстанавливает информационную базу.
- Платный Anthropic API не используется. Claude подключается только по подписке Max через официальный Claude Code.
