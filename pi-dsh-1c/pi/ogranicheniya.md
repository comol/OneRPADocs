# Ограничения Pi

Это рабочая beta для практической разработки, не обещание полного контура сопровождения.

- MCP, Cognee, OpenViking, EDT-MCP и Windows-MCP поставка не устанавливает и не запускает. Без семи профильных серверов сессия в degraded, а не «сборка сломана».
- Отдельной защиты информационной базы нет. Загрузка и другие операции с базой идут с обычным подтверждением и в BUILD. Берите тестовую копию.
- Структурный XML руками не правится ни в каком режиме. `edit` и `write` его не принимают.
- Произвольный PowerShell модели недоступен. Исполняются только хешированные скрипты навыков.
- Встроенного отката хода нет. Пакет теневых снимков всего проекта отключён: на большой выгрузке он слишком дорог. Файлы возвращайте через Git или свою копию. Базу — через `/restore-testbase` или резервную копию.
- Дерево Pi Web показывает локальную выгрузку, а не живой индекс MCP.
- Локальный плагин — код с правами процесса. Статический скан и smoke не являются песочницей. `disable` и `rollback` не выгружают уже выполненный код без перезапуска.
- Классификация «этот инструмент пишет» в ASK и PLAN идёт по имени инструмента, не по песочнице.
- Java и BSL Language Server входят в архив каждой платформы. В Linux и macOS нет Warp, Pi Web, COM и скриптов навыков на Windows PowerShell: см. [Linux и macOS](../platformy.md).
- Защита персональных данных по умолчанию выключена, включается `/pii on`. Это эвристика, а не юридическое обезличивание: см. [Защита персональных данных](../zashchita-pdn.md).
- Ротация аккаунтов и резервные модели срабатывают только до начала ответа. Начатый ответ и вызовы инструментов не повторяются.
- Русский задан в собственных текстах бандла. Панели части внешних пакетов остаются английскими. `/lang think` выключен.
- Платный Anthropic API не используется. Claude — подписка Max через CLI `claude`. Cursor подключается действующей подпиской через `/cursor-login` и сохраняет лимиты этой подписки. Вход в приложение Cursor сам по себе сессию Pi не авторизует.
- Web-режим — не официальный графический клиент Pi. Он слушает только localhost. Встроенный терминал Web выключен.
- Фоновые ходы модели, таймеры ретроспектив и автоправки сами по себе не включены. `/later`, `/check` и heartbeat не вызывают модель без уже заданного вами действия.
- Качество редкого веб-поиска не гарантируется. Он не заменяет MCP 1С.

Если поведение расходится с этой страницей, смотрите `/status1c` и `Pi-1C.exe --doctor`: они показывают фактический режим сессии, а не желаемый.
