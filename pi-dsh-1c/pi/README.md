# Pi 1C

Изолированная сборка Pi Coding Agent для разработки на «1С:Предприятие».

- Версия бандла: **1.1.0**
- Ядро: `@earendil-works/pi-coding-agent` **1.4.0**
- Поставка: Windows x64, файл `Pi-1C.exe`
- Сайт сборки: [vibecoding1c.ru](https://vibecoding1c.ru/)

Штатный Pi даёт чат, модель и сессии. Этот бандл добавляет восемь MCP 1С, поиск через них, OpenSpec, слой знаний, доступ ASK/PLAN/BUILD, автономию и локальные расширения. Имена команд английские, описания русские.

## Как устроен запуск

Обычный `Pi-1C.exe` или команда `startpi1c` без аргументов открывает список **проекты → разговоры**: имена, поиск, история. Справа выбирается среда: **Warp**, **Pi Web** или обычный терминал. В Warp и терминале историю открывают Enter, двойной щелчок или кнопка. Web открывает выбранный проект, а конкретный разговор выбирается уже в браузере.

Прямой терминал без этого окна: перетащите папку проекта на EXE или запустите `Pi-1C.exe -WorkingDirectory <папка>`.

| Среда | Команда |
|---|---|
| Терминал | `Pi-1C.exe -WorkingDirectory <папка>` |
| Warp, вкладка комплектного терминала | `Pi-1C.exe -Warp -WorkingDirectory <папка>` |
| Браузер только на `127.0.0.1` | `Pi-1C.exe -Web -WorkingDirectory <папка>` |
| Мастер проекта, `.dev.env` и модель | `Pi-1C.exe --setup` |
| Новый каталог и мастер | `Pi-1C.exe --new-project <папка>` |
| Запомнить существующую папку | `Pi-1C.exe --add-project <папка>` |
| Диагностика без модели | `Pi-1C.exe --doctor -WorkingDirectory <папка>` |

Все флаги: `Pi-1C.exe --help`. Каталог состояния: `Pi-1C.exe --settings`.

Warp входит в поставку и хранит своё состояние внутри каталога состояния Pi. Следующие проекты открываются вкладками того же окна. Web — community-интерфейс `pi-web-ui`: встроенный терминал в нём выключен, потому что он обходил бы ограничения бандла.
